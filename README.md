# Aurora · дизайн-система

Токены, стили, эталонные компоненты и каталог для веб-интерфейсов GPS-мониторинга.
Пакет: `@primasoftllc/design-system` в GitHub Packages. Исходники и документация
редактируются в этом репозитории.

## С чего начать

| Задача | Что читать |
|---|---|
| Подключить систему в приложение | [Использование в Angular](docs/usage.md) — установка, скоупы, графики, линтер, приёмка |
| Сделать экран | [Дизайн-правила](docs/design.md) и примеры в каталоге компонентов |

| Разрабатывать Angular UI kit | [Angular UI kit](ng-ui-kit/README.md) — структура, команды и правила компонентов |

По мере необходимости: [имена токенов](docs/tokens.md),
[миграция старого приложения](docs/migration.md), [версии и релиз](docs/release.md),
[история изменений](CHANGELOG.md). Инструкции агентам — [AGENTS.md](AGENTS.md).

## Запустить каталог

Node 22 из mise. Из корня репозитория:

```bash
mise exec -- npm ci
mise exec -- npm run dev
```

Откройте http://127.0.0.1:5173. Каталог обновляется при правках и показывает
компоненты, их API, состояния и токены. Для раскладки экрана начните с карточек
`Monitoring`, `Admin` и `AppShell`.

## Что поставляется приложению

CSS, шрифты, токены, конфиг stylelint и Angular-сервис скоупов с директивой;
интеграция ECharts подключается отдельно. React-компоненты поставляются готовыми
и служат эталоном поведения. Angular UI kit поставляется из этого же пакета;
первый компонент — [DsButtonComponent](ng-ui-kit/src/components/button/README.md), `button[dsButton]`.
Доступ к приватному пакету и пошаговая настройка — в [руководстве](docs/usage.md).

Angular-вход собран на 19.2.25 и проверяется в Angular 19.2.25 и 20.3.34;
интеграция графиков — ECharts 6.1+.
Peer range — `^19.2.25 || >=20.3.34`; более новые major требуют отдельной проверки.
Архитектура и критерии готовности — в [правилах UI kit](ng-ui-kit/docs/development.md).
Стили и токены можно использовать без этих зависимостей.

Для React 18.3 корневой импорт поставляет скомпилированный ESM и TypeScript-типы:

```tsx
import { DsButton } from '@primasoftllc/design-system';
import '@primasoftllc/design-system/styles.css';

export function SaveButton() {
  return <DsButton tone="primary">Сохранить</DsButton>;
}
```

Транспиляция JSX внутри пакета не требуется. React, React DOM и их типы устанавливает
React-приложение; для потребителя только CSS они остаются необязательными.
Браузерные цели и проверки описаны в [правилах разработки](CONTRIBUTING.md#browser-support).
