Обычный выбор

Нажмите на символ, подпись или пояснение. В фокусе Space переключает значение; Enter его не переключает.

Недоступное действие

Disabled использует нативную блокировку и исключает input из Tab. Причина ограничения остаётся рядом с подписью.

Сравнение состояний

В доступной колонке можно переключать контролы. Indeterminate отображает минус независимо от checked; при нажатии становится checked=true и indeterminate=false.

@for (state of states; track state.name) { }
Начальное состояние Доступен Недоступен
{{ state.name }}

Правила применения

  • Используйте Checkbox для независимых опций или выбора нескольких объектов. Выбор одного варианта и переключатель немедленно применяемой настройки — отдельные компоненты.
  • Родитель вычисляет checked и indeterminate для группы. При indeterminate=true виден минус независимо от checked; действие пользователя выбирает контрол и снимает частичное состояние.
  • Label и description образуют кликабельный текстовый блок. Чекбокс центрируется относительно всей его высоты; свободная ширина строки не становится областью нажатия.
  • Без label задайте aria-label или aria-labelledby. Description автоматически связан с input; внешний aria-describedby дополняет его.
  • В Reactive Forms используйте boolean-контрол, задавайте disabled через форму. Programmatic setValue и reset не создают checkedChange; пользовательское изменение создаёт событие.
  • Required, отображение ошибок, radio и дерево как самостоятельный компонент пока в API не входят.

Пример подключения

Импортируйте DsCheckboxComponent из публичного Angular-входа и подключите общий styles.css. Для Reactive Forms добавьте ReactiveFormsModule.

Параметры

Параметр Тип По умолчанию Назначение
checked boolean false Выбранное значение вне Angular Forms.
indeterminate boolean false Частичный выбор; не отдельное значение формы.
disabled boolean false Нативная блокировка, дополняющая disabled формы.
compact boolean false Область нажатия 24 px для табличной строки.
label string | undefined Нет Видимая подпись.
description string | undefined Нет Пояснение под подписью.
inputId string | undefined Генерируется ID внутреннего input для внешних связей.
name string | undefined Нет Имя поля для FormData. Отмеченный input передаёт нативное значение on.
aria-label / aria-labelledby string | undefined Из label Доступное имя внутреннего input; задайте явно, если нет видимой подписи.
aria-describedby string | undefined Нет Внешние ID описаний дополняются ID description.

События checkedChange и indeterminateChange передают boolean. Поддерживаются [(checked)] и [(indeterminate)]. Checkbox сам меняет локальное состояние при действии пользователя; приложение может обновить входное значение. При подключённом CVA значение принадлежит Angular Forms. Disabled задаётся формой или параметром; любой из них запрещает взаимодействие.
