Правила применения

  • Используйте один FAB для главного действия области. Примеры выше показывают варианты, которые не нужно одновременно размещать на экране.
  • Для неоднозначного или важного действия предпочитайте extended с понятной подписью.
  • Размещение, внешние отступы и свободное место вокруг кнопки задаёт родитель. Компонент не закрепляет себя у края экрана.
  • Label обязателен и не должен быть пустым: это доступное имя и текст подсказки. Иконка декоративная; имя символа проверяет приложение.
  • Приложение выполняет запросы, меняет loading, сообщает результат и объясняет причину disabled. Не меняйте подпись во время загрузки, если нужно сохранить ширину.
  • Enter и Space активируют нативную кнопку. Для перехода используйте ссылку.

Обычные действия и кнопки с иконкой показаны на странице Button .

Пример подключения

Подключите общий styles.css и импортируйте DsFabComponent из публичного Angular-входа. Дополнительный импорт иконки не требуется.

Параметры

Параметр Тип / значения По умолчанию
label string; обязательное непустое имя —
icon string; имя Material Symbols add
tone DsFabTone: primary, accent, surface primary
size DsFabSize: sm, md, lg md
extended boolean; видимая подпись false
loading boolean; блокировка активации с сохранением фокуса false
disabled boolean; нативная блокировка false
type button, submit, reset button
aria-busy, aria-disabled string | boolean | null; внешние значения восстанавливаются после loading null
aria-describedby string | null; внешние описания сохраняются при показе подсказки null

Булевы inputs поддерживают атрибутную запись и binding. Событие click нативное; name, value, form и остальные HTML-атрибуты остаются на кнопке. Подпись задаёт label, проекции содержимого и дополнительных outputs нет. Публичные экспорты: DsFabComponent, DsFabTone, DsFabSize.
