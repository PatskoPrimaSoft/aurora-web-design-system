Правила применения

  • Выбирайте символ по назначению из словаря иконографики . API принимает string; корректность имени остаётся ответственностью приложения. Неизвестное имя может отобразиться буквами: проверки и подстановки другого символа нет.
  • Размер выбирайте по роли. Не переопределяйте отдельно font-size, ширину или высоту иконки.
  • Цвет наследуется от родителя; для собственной разметки используйте семантические токены.
  • Без непустого label иконка скрыта от экранного диктора. Пробельная подпись считается отсутствующей. Не задавайте отдельно управляемые компонентом role, aria-label и aria-hidden.
  • Иконка не является действием и не получает фокус. Для действия используйте содержащую её кнопку или ссылку с доступным именем. Область нажатия и внешние отступы задаёт родитель.

Композиция кнопки с иконкой показана на странице Button в примерах с подписью и без неё.

Пример подключения

Подключите пакетный styles.css и добавьте DsIconComponent из @primasoftllc/design-system/angular в imports компонента приложения. Полный пример импорта раскрывается под первым сценарием.

Шрифт Material Symbols Outlined поставляется локально; дополнительный CDN не нужен. Подключение общих стилей описано в руководстве Angular .

Параметры

Параметр Тип По умолчанию Назначение
name string Обязательный Имя глифа в поставляемом шрифте.
size DsIconSize md Роль: xs, sm, md или lg.
label string | undefined Нет Доступное имя самостоятельной смысловой иконки.
rotate number 0 Поворот по часовой стрелке в градусах; например, [rotate]="90".

Публичные экспорты: DsIconComponent и тип DsIconSize. Собственных событий и проекции содержимого нет.

Токены

Токен Cozy / compact Назначение
--ds-icon-xs 14 / 12 px Вспомогательный символ рядом с мелким текстом.
--ds-icon-sm 16 / 14 px Плотная строка.
--ds-icon 20 / 18 px Иконка внутри обычного контрола.
--ds-icon-lg 24 / 20 px Отдельно стоящая иконка.

Толщина — wght=400. Оптическая поправка navigation применяется внутри области. Собственного токена цвета у иконки нет; подробные роли цвета и правила выбора символов — в «Иконографике» .
