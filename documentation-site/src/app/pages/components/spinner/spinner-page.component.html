Живые примеры

Обновление данных

Spinner показывает неизвестный прогресс. Приложение сохраняет прежние данные, блокирует повторный запуск и сообщает результат.

@if (refreshing()) { }

{{ report() }}

{{ refreshMessage() }}

Размеры

Диаметр не зависит от плотности: 16–20 px для строки, 32 px для области, 48 px для страницы. Толщина кольца рассчитывается автоматически.

@for (size of sizes; track size) { {{ size }} px }

Цвет и поверхность

Brand использует цвет бренда, muted — приглушённый цвет текста. Inverse наследует currentColor от родителя; контрастный цвет задаёт контейнер.

brand muted inverse

Задержка появления

Задержка 500 ms помогает избежать мелькания при короткой фоновой операции. Место зарезервировано сразу; до появления кольца Spinner не объявляет загрузку.

@if (delayed()) { }

{{ delayMessage() }}

Ошибка и повторная попытка

Spinner не обрабатывает ошибки. Пример имитирует неудачу первой попытки и успешный повтор; фокус остаётся на той же кнопке.

@if (retryState() === 'loading') { }

{{ retryState() === 'done' ? 'Получены сведения о четырёх объектах.' : 'Данные отчёта пока недоступны.' }}

{{ retryMessage() }}

Одно объявление загрузки

Самостоятельный Spinner объявляет label через role=status. Если видимый текст уже находится в role=status, скрывайте от скринридера только декоративный Spinner.

Правила применения

  • Используйте Spinner, когда объём работы неизвестен. Он не показывает процент и не определяет завершение операции.
  • Для действия в кнопке используйте её loading; для загружаемого содержимого с известной геометрией позднее предусмотрим отдельный Skeleton. Spinner не заменяет данные без необходимости.
  • После явного запуска показывайте индикатор сразу. Задержка подходит для фоновых обновлений, где важно избежать мелькания.
  • Задавайте осмысленный непустой label. Не объявляйте одну загрузку одновременно Spinner и вторым status. Нефокусируемый Spinner не блокирует взаимодействие.
  • Приложение добавляет компонент через @if, задаёт aria-busy области данных, защищает от повторных действий, сообщает ошибку и убирает индикатор после завершения.
  • При уменьшении движения плавное появление отключается, но вращение сохраняется. Это поведение общих стилей дизайн-системы.

Загрузка внутри кнопки показана на странице Button . Внутренние индикаторы Button и FAB на этом этапе не заменяются.

Пример подключения

Добавьте DsSpinnerComponent из публичного Angular-входа в imports и подключите общий styles.css. Иконка, изображение и SVG для кольца не нужны.

Параметры

Параметр Тип По умолчанию Назначение
size number 20 Диаметр в px, независимый от плотности. Некорректное или неположительное значение заменяется на 20.
tone DsSpinnerTone brand brand, muted или inverse.
label string Обязателен Непустое доступное название операции; видимый текст автоматически не выводится.
delay number 0 Задержка появления в ms. Отрицательные и неконечные значения означают отсутствие задержки.

Публичные экспорты: DsSpinnerComponent, DsSpinnerTone. Числовые inputs поддерживают binding и числовые атрибуты. Толщина рассчитывается по правилу max(2, round(size / 9)), ограничивается половиной диаметра для очень маленьких размеров. Параметров loading, thickness, событий и Angular Forms нет.

Изменение delay перезапускает отсчёт; изменение размера, цвета или label не перезапускает операцию. При уничтожении таймер отменяется.

Токены и анимация

Токен / правило Назначение
--ds-brand Цвет brand.
--ds-fg-muted Цвет muted.
currentColor Наследуемый цвет inverse; кольцо имеет opacity 0.85, как в эталоне.
--ds-radius-circle Круглая форма рамки.
ds-spin Вращение 700 ms linear infinite.
ds-spinner-enter Появление 300 ms ease-out; отключается при reduced motion.
