Живые примеры

Обычное действие

Подпись передаётся содержимым кнопки, действие — нативным событием click.

Нажатий: {{ clicks() }}

Тоны

Выбирайте оформление по назначению действия. Inverse показан на инверсной поверхности.

@for (tone of tones; track tone) { }

Нажата кнопка: {{ selectedTone() }}

Размеры и плотность

Связанные действия используют одинаковый размер. Плотность меняет высоту и отступы через токены.

@for (size of sizes; track size) { }

Нажат размер: {{ selectedSize() }}

Иконки и кнопка без текста

Внутренние иконки декоративные. Без подписи обязательно доступное имя на самой кнопке.

@for (size of sizes; track size) { {{ size }} }

Действий выполнено: {{ added() }}

Без проецируемой подписи и с одной иконкой кнопка квадратная: 28/36/44 px в cozy и 24/30/36 px в compact. Это тот же Button без отдельного IconButton и автоматической подсказки.

Недоступное действие

Disabled использует нативную блокировку и исключает кнопку из Tab. Причину показывайте рядом.

{{ locked() ? 'Действие временно недоступно. Нажмите «Разрешить действие», чтобы попробовать.' : 'Действие доступно.' }}

Выполнено: {{ performed() }}

Загрузка

Приложение управляет loading и сообщает результат. Кнопка сохраняет размеры, доступное имя и фокус.

{{ saveMessage() }}

Запущено операций: {{ saves() }}

Длинная подпись и полная ширина

Ширину области задаёт родитель. FullWidth заполняет её, длинный текст переносится без обрезания.

Кнопка в форме

Submit отправляет форму, reset возвращает исходное значение, обычная кнопка форму не отправляет. Поле здесь нативное — только для демонстрации поведения формы.

{{ formMessage() }}

Правила применения

  • Выделяйте одно главное действие через primary. Secondary и ghost подходят для сопутствующих действий, subtle — для мягкого брендового акцента, danger — для разрушительного действия. Inverse используйте на инверсной поверхности.
  • Подпись объясняет результат: «Сохранить изменения», «Удалить объект». Для переходов используйте ссылку, а не кнопку.
  • Не помещайте внутрь кнопки ссылки, поля и другие интерактивные элементы. Внешние отступы и расположение задаёт родитель.
  • Loading не запускает запрос самостоятельно. Приложение меняет состояние, сообщает результат и обрабатывает ошибку. Активация и отправка формы этой кнопкой блокируются, но фокус сохраняется. Не меняйте подпись во время загрузки, если нужно сохранить ширину.
  • Disabled исключает кнопку из Tab. Объясняйте причину ограничения рядом; не отключайте отправку формы только из-за незаполненных полей — покажите ошибки после отправки.
  • Без текста используйте одну иконку и aria-label на кнопке. Иконка декоративная, фокус принадлежит кнопке. Квадратная геометрия включается при пустой подписи; fullWidth явно растягивает кнопку. Подсказка автоматически не создаётся.
  • Нативные type, id, name, value, form и ARIA-атрибуты остаются на button. Для собственной активации используйте (click), дополнительных outputs нет.

Правила выбора символов — в «Иконографике» , API изображения — на странице Icon.

Пример подключения

Подключите общий styles.css и добавьте DsButtonComponent из @primasoftllc/design-system/angular в imports. Отдельно импортировать DsIconComponent для icon/iconRight не требуется.

Для действия по умолчанию используется type="button"; submit и reset задаются явно. Подробности — в подключении Angular .

Параметры

Параметр Тип / значения По умолчанию Назначение
tone DsButtonTone primary primary, secondary, subtle, ghost, danger, accent, inverse.
size DsButtonSize md sm, md или lg; учитывает плотность.
icon, iconRight string | undefined Нет Имя иконки слева или справа. Корректность имени проверяет приложение.
loading boolean false Индикатор выполнения и блокировка повторной активации.
disabled boolean false Нативное недоступное состояние.
fullWidth boolean false Заполняет ширину родителя, в том числе у кнопки без текста.
type button, submit, reset button Нативное поведение в форме.
aria-busy, aria-disabled string | boolean | null null Внешние ARIA-значения; loading временно устанавливает true, затем возвращает заданные значения.

Публичные экспорты: DsButtonComponent, DsButtonTone и DsButtonSize. Булевы inputs поддерживают атрибутную запись и binding. Подпись передаётся проекцией. ControlValueAccessor кнопке не нужен.

Токены Назначение

--ds-control-h-sm, --ds-control-h, --ds-control-h-lg Минимальная высота; ширина и высота кнопки с одной иконкой без подписи.
--ds-control-pad-x, --ds-gap-sm Отступы md/lg и интервал между иконкой и подписью. У sm горизонтальный отступ 10 px; у одной иконки без подписи — 0.

--ds-icon-sm, --ds-icon Иконки и индикатор загрузки: уменьшенный размер для sm, обычный для md/lg.
--ds-focus-width, --ds-focus-color, --ds-focus-offset Клавиатурный фокус.
--ds-transition-control Переходы оформления.

Размеры и цвета наследуют бренд, оформление и плотность. Отдельных параметров цветов и пиксельных размеров у кнопки нет.
