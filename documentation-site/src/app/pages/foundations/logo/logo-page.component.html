Логотип в шапке

В шапке используйте знак и название продукта. Готовая DsAppHeader задаёт плашку, размеры и отступы.

Обычная шапка

Пример обычной шапки будет собран после подготовки необходимых Angular-компонентов.

Мало места

Пример компактной шапки будет собран после подготовки необходимых Angular-компонентов.

Скрывать название и метку DEV решает приложение: DsAppHeader не переключает композицию автоматически. В компактном примере название сохранено для скринридера.

Проверьте знак в обоих оформлениях переключателем вверху страницы: брендовая плашка может становиться светлее, а белые детали — терять контраст. Тема не перекрашивает само изображение.

Знак и название
Основной вариант: помогает сразу узнать продукт. Метку DEV добавляйте, только если важно различать окружения.
Только знак
Когда места мало и из контекста уже понятно, какой продукт открыт.
Другой бренд
Используйте его собственный ресурс и название вместо Aurora.

Знак и фон

Одинаковый белый знак на светлой поверхности: с плашкой детали видны, без неё — сливаются с фоном.

Рекомендуется

Брендовая плашка отделяет белые детали от светлой поверхности.

Избегайте

Без подложки белая стрелка и кольцо теряются.

Правила применения

  • Сохраняйте исходный знак. Не растягивайте изображение и не перекрашивайте отдельные части. Для Aurora используйте прозрачный PNG с белой стрелкой, кольцом и жёлтыми дугами.
  • Проверяйте всю композицию. Учитывайте длинное название, метку окружения и соседние действия в шапке.
  • Называйте по назначению. Для самостоятельного изображения — alt="Aurora", для ссылки на главную — aria-label="На главную Aurora". Если название уже есть рядом, у изображения допустим пустой alt. Шапки выше не являются ссылками.
