Сортировка в списке

Сортировка меняет порядок, но сохраняет состав списка. Поле и направление выбираются раздельно и применяются вместе.

Пример сортировки списка появится при наполнении Angular-примеров.

Краткая памятка

Название
«А → Я / Я → А» — для поиска знакомого объекта в справочнике.
Дата или время
«Сначала новые / Сначала старые» — для последних записей или истории.
Число
«Сначала больше / Сначала меньше» — для сравнения значений, например скорости.

В списке или наборе карточек используйте меню рядом с содержимым. Если есть заголовки столбцов, сортировку удобнее разместить в таблице.

Правила применения

  • Задайте начальный порядок. Выберите его по задаче: в справочнике — по названию, в журнале — сначала новые. Сброс возвращает этот порядок.
  • Показывайте применённый выбор. Название поля и направление должны быть доступны без открытия меню. Их можно разместить над списком.
  • Сохраняйте результаты. Сортировка меняет порядок, а фильтр — состав списка. Не добавляйте сортировку в чипы применённых фильтров.

Подключение и данные

Интерфейс сортировки позволяет выбрать поле и направление и применить их вместе. Приложение перестраивает полностью загруженный список либо запрашивает отсортированные данные с сервера. Публичный API отдельного компонента меню пока не определён.

Показать технические подробности

Ниже описаны общие правила взаимодействия, а не контракт готового библиотечного компонента.

Поле и направление

Поле и направление выбираются раздельно и применяются вместе. Подписи направления зависят от поля: например, «Сначала новые» для даты или «А → Я» для названия. Сброс возвращает начальный порядок. Группировка объединяет объекты по признаку и не имеет направления; её реализует приложение. Не переставляйте шаги процесса и уровни дерева.

Порядок всего набора

Сортируйте в браузере только полностью загруженный список. При постраничной загрузке передавайте выбор серверу и возвращайтесь на первую страницу, сохраняя фильтры. Текст сравнивайте с учётом языка, числа — как числа, даты — по времени. Для одинаковых значений задайте устойчивый дополнительный порядок, например по идентификатору.

Клавиатура и собственная кнопка

Кнопка открытия должна иметь понятное доступное имя и работать с клавиатуры. Enter или Space открывает меню, стрелки перемещают фокус, Space выбирает пункт. Escape отменяет черновик и возвращает фокус на кнопку открытия. Точное поведение составного контрола согласуется при его реализации.
