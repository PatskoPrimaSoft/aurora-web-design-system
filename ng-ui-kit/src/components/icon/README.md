# DsIconComponent

Standalone-компонент `ds-icon` из Angular UI kit. Общие правила
выбора символов, размеров и доступности — в [Иконографике](../../../../design-system/components/DsIconography/preview.html).
Подключите пакетный `styles.css` по [руководству](../../../../design-system/docs/usage.md):
он поставляет локальный Material Symbols Outlined, без CDN.

Публичная страница `/components/icon` показывает обычное использование, размеры,
наследование цвета, доступное имя и поворот. Для действий используйте содержащую
иконку кнопку или ссылку; композиция с кнопкой будет описана на странице Button.

Для проверки поставки общий пример `ng-ui-kit/tests/consumers/shared/icon-demo.ts`
подключён к независимым Angular 19 и 20 consumers. Сценарии проверяют публичный
импорт и тип размера, обновление inputs, доступность, наследование цвета и плотности.
Добавление сценариев не заменяет их запуск перед выпуском.

## Пример подключения

```ts
import {ChangeDetectionStrategy, Component} from '@angular/core';
import {DsIconComponent} from '@primasoftllc/design-system/angular';

@Component({
  selector: 'app-icon-example',
  imports: [DsIconComponent],
  changeDetection: ChangeDetectionStrategy.OnPush,
  template: `<ds-icon name="warning" /> <span>Нет связи с объектом</span>
    <ds-icon name="lock" label="Доступ ограничен" />
    <ds-icon name="navigation" [rotate]="90" label="Направление движения: восток" />`,
})
export class IconExample {}
```

## Angular API

Публичные экспорты: `DsIconComponent` и тип `DsIconSize` из `/angular`.

| Input | Тип | По умолчанию | Назначение |
| --- | --- | --- | --- |
| `name` | `string` | обязательный | Имя глифа Material Symbols Outlined |
| `size` | `DsIconSize`: xs, sm, md, lg | md | Системная роль размера |
| `label` | `string \| undefined` | нет | Доступное имя самостоятельной смысловой иконки |
| `rotate` | `number` | 0 | Поворот по часовой стрелке в градусах |

Корректность имени и выбор символа — ответственность приложения.
Имя выводится текстом; лигатура шрифта превращает его в глиф. Компонент
не ограничивает имена словарём и не подменяет неизвестные символы. Выбор
должен соответствовать Иконографике Aurora. Если имени нет в локальном шрифте,
могут отобразиться буквы. SVG, изображения и произвольное содержимое не принимаются.

Размеры xs/sm/md/lg используют `--ds-icon-xs`, `--ds-icon-sm`, `--ds-icon`,
`--ds-icon-lg`: область и глиф меняются вместе и наследуют плотность.
Цвет наследуется от родителя; отдельного input цвета нет. Для собственной
разметки задавайте родителю семантический цветовой токен. Тема, оформление
и плотность наследуются без обращения к глобальному сервису.

Без непустого `label` компонент декоративный (`aria-hidden="true"`). С `label`
он получает `role="img"` и `aria-label`; подпись из одних пробелов считается отсутствующей.
Используйте `label` для доступного имени: управляемые компонентом `role`,
`aria-label` и `aria-hidden` не следует задавать отдельно. Видимая подсказка не создаётся.
Для подписи, содержащей направление, приложение обновляет текст вместе с углом.

Иконка не интерактивна: не добавляет tabindex, обработчики или собственные
события. Действие и клавиатурный фокус принадлежат содержащей её кнопке или ссылке.
Размер области нажатия и внешние отступы задаёт родитель.
Оптическая поправка `navigation` применяется внутри области; толщина — wght=400.
