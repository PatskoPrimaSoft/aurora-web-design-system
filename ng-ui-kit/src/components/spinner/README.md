# DsSpinnerComponent

Нефокусируемый индикатор операции с неизвестным прогрессом. Селектор
`ds-spinner`, публичный импорт — `@primasoftllc/design-system/angular`.
Компонент не запускает запросы, не блокирует интерфейс и не определяет завершение.

```html
@if (loading()) {
  <ds-spinner label="Загрузка отчёта" [size]="32" [delay]="500"></ds-spinner>
}
```

Добавьте DsSpinnerComponent в imports страницы и подключите пакетный styles.css.
Кольцо рисуется CSS-рамкой с прозрачным участком; DsIcon, SVG и картинки не используются.

## API

| Input | Тип | По умолчанию |
| --- | --- | --- |
| label | string; обязательное непустое название операции | — |
| size | number; диаметр в px | 20 |
| tone | DsSpinnerTone: brand, muted, inverse | brand |
| delay | number; задержка появления в ms | 0 |

Числовые параметры используют numberAttribute: поддерживаются binding и
числовые атрибуты. Неположительный/неконечный size заменяется на 20;
отрицательный/неконечный delay — на 0. Размеры 16–20 px подходят для строки,
32 — для области, 48 — для страницы. Плотность диаметр не меняет.
Толщина вычисляется как max(2, round(size / 9)), ограничивается половиной
диаметра для очень маленьких размеров. Отдельного thickness в первой версии нет.

Label передаёт приложение: Angular-словарь служебных строк пока не введён.
Параметров loading, visible, событий и ControlValueAccessor нет.
Изменение size, tone или label не перезапускает задержку. Изменение delay
перезапускает отсчёт; предыдущий таймер отменяется. Уничтожение компонента
очищает таймер. Приложение добавляет и убирает Spinner через @if.

## Дизайн и доступность

- До истечения delay внешний размер уже задан; кольца, role=status и
  доступного объявления ещё нет. Задержка подходит для коротких фоновых операций;
  после явного действия предпочтительно показывать ожидание сразу.
- После появления хост получает role=status и aria-label; название также есть
  в визуально скрытом тексте. Кольцо декоративное и скрыто от скринридера.
- Области данных задавайте aria-busy. Не удаляйте прежние данные без необходимости,
  сохраняйте фокус и защищайте от повторного запуска на стороне приложения.
- Если другое role=status уже сообщает о той же загрузке, задайте Spinner
  aria-hidden="true" или оберните его в скрытую от скринридера область.
- Brand использует --ds-brand, muted — --ds-fg-muted, inverse — currentColor
  родителя; opacity кольца inverse равна 0.85, как в эталоне React.
- Круглая рамка использует --ds-radius-circle. Анимации и визуально скрытая подпись
  берутся из общих правил motion.css по data-ds-spinner-*; локальной копии
  keyframes нет. Появление — 300 ms ease-out, вращение — 700 ms linear infinite.
- Reduced motion отключает только появление. Вращение сохраняется, как требует
  дизайн-система; отдельного флага анимации не добавлено.
- Внешние отступы, размещение, состояние операции и обработка ошибок принадлежат родителю.

SSR/hydration пока не заявлены, как и у текущего Angular UI kit.

## Примеры и проверки

Новый сайт: **Компоненты → Обратная связь → Spinner**, маршрут /components/spinner.
Шесть сценариев: обновление данных, размеры, цвета, задержка, ошибка/повтор,
одно доступное объявление загрузки. Таймеры демонстраций принадлежат странице
и освобождаются при уходе с неё; код хранится в соседнем snippets-файле.

Добавлены сценарии установленного пакета Angular 19/20 и браузерная группа
spinner (также включена в общий components). Проверяются геометрия, токены,
доступное имя, задержка/резервирование места, смена параметров, отсутствие
фокуса, уничтожение, reduced motion, работа примеров и доступность.
Точечные сборки и браузерные проверки прошли на Angular 19.2.25 и 20.3.34,
а также на новом сайте в четырёх режимах и двух ширинах. Полный verify не запускался.

DsSpinnerComponent используется внутри Button/FAB для loading и в статье
«Анимация и переходы» → «Уменьшение движения». В кнопках индикатор декоративный;
его цвет и размер области задаёт кнопка, доступность остаётся на кнопке.
