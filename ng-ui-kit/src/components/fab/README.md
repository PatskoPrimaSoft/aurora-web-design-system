# DsFabComponent

Кнопка главного действия области, селектор `button[dsFab]`. Импортируется из
`@primasoftllc/design-system/angular`; общий styles.css подключается один раз.
Примеры нового сайта: **Компоненты → FAB**, маршрут `/components/fab`.

```html
<button dsFab label="Добавить объект" (click)="create()"></button>
<button dsFab extended icon="save" label="Сохранить" [loading]="saving()"
  (click)="save()"></button>
```

Используйте один FAB для главного действия области. Предпочитайте extended,
если одна иконка неоднозначна. Размещение и внешние отступы задаёт родитель;
компонент самостоятельно не закрепляется у края экрана.

| Input | Тип | По умолчанию |
| --- | --- | --- |
| label | string, обязательное непустое имя | — |
| icon | string, имя Material Symbols | add |
| tone | DsFabTone: primary, accent, surface | primary |
| size | DsFabSize: sm, md, lg | md |
| extended | boolean | false |
| loading | boolean | false |
| disabled | boolean | false |
| type | button, submit, reset | button |
| aria-busy, aria-disabled | string, boolean или null | null |
| aria-describedby | string или null | null |

Булевы inputs используют booleanAttribute. Label задаёт доступное имя,
подсказку и видимую подпись при extended; проекция не используется. Иконка
декоративная, имя символа не проверяется. Событие click и HTML-атрибуты нативные.

Диаметры sm/md/lg — 40/48/56 px, иконки — 18/24/24 px независимо от плотности.
Цвета, шрифт, круглая/капсульная форма, тени и состояния используют токены
дизайн-системы. Extended ограничен шириной родителя, длинная подпись сокращается.

Loading сохраняет геометрию и фокус, выставляет aria-busy/aria-disabled и
блокирует активацию до обработчика приложения и нативной отправки формы.
После loading восстанавливаются внешние ARIA-значения. Disabled использует
нативную блокировку и исключает кнопку из Tab. Запросы, состояние загрузки,
результат и объяснение недоступности принадлежат приложению.

Подсказка показывается при наведении и фокусе: у круглой кнопки всегда,
у extended — при обрезанной подписи. Escape закрывает её, сохраняя фокус;
событие не передаётся внешнему слою при открытой подсказке. Поддерживается
переход указателя на подсказку. Внешний aria-describedby сохраняется.
Используется нативный Popover API (ручной режим, верхний слой браузера), без
новых зависимостей; DOM остаётся в локальном скоупе токенов. Слушатели,
наблюдатель размеров и таймер закрытия освобождаются при уничтожении.
SSR, hydration и старые браузеры без Popover API пока не заявлены.

Добавлены сценарии установленного пакета в потребителях Angular 19/20 и
браузерные проверки страницы во всех четырёх режимах и двух ширинах.
2026-10-30 production-сборки и выбранные браузерные проверки сайта и
потребителей Angular 19/20 прошли. Полный verify не запускался.
