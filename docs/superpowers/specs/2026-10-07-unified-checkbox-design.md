# Единый DsCheckbox

## Цель

В каталоге и публичном API остаётся один компонент выбора — `DsCheckbox`.
Он покрывает формы, фильтры, выбор строк таблицы, объектов и групп дерева.
Внешний вид, токены, размер символа 18 px и граница 2 px сохраняются.
Пользователь согласовал объединение без совместимых алиасов.

## Публичный API

```ts
type DsCheckboxState = 'unchecked' | 'checked' | 'indeterminate';

interface DsCheckboxProps {
  state?: DsCheckboxState; // по умолчанию unchecked
  onChange?: (nextState: 'unchecked' | 'checked') => void;
  label?: React.ReactNode;
  ariaLabel?: string;
  description?: string;
  radio?: boolean;
  disabled?: boolean;
  name?: string;
  value?: string;
  hit?: number | string;
}
```

`state` заменяет `checked` и `indeterminate`; callback получает новое состояние,
а не DOM-событие. Компонент управляемый: потребитель обновляет `state`.
Без `onChange` пользовательское взаимодействие не меняет состояние.
Для радио допустимы только `unchecked` и `checked`; переданный
`indeterminate` нормализуется в `unchecked` и не объявляется смешанным состоянием.

С подписью используется `label`; без видимой подписи обязателен `ariaLabel`.
`description` связывается с input через `aria-describedby`.
Не вводятся режимы button/decorative и дублирующие булевы props.

## Реализация и поведение

Основа — настоящий `input type="checkbox"` или `input type="radio"` внутри label.
Символ рисует приватная функция; отдельного публичного декоративного компонента нет.
Настоящий input остаётся фокусируемым и доступным вспомогательным технологиям.
Нейтральные disabled-токены, hover и CSS-кольцо фокуса сохраняются.

Чекбокс переключается пробелом и нажатием всей области label:
`unchecked` / `indeterminate` → `checked`, `checked` → `unchecked`.
`indeterminate` задаётся также DOM-свойством input. Для смешанного состояния
нативный checked устанавливается в false, чтобы активация выбирала всё.
Радио использует нативную группировку по name, стрелки и Space; выбор уже
выбранного радио не снимается. Disabled не получает фокус и не вызывает callback.

Enter больше не переключает выбор, как у прежнего DsCheckButton: используется
нативная клавиатурная модель checkbox/radio без ручного обработчика Enter.
Выбор не должен открывать строку, раскрывать группу или отправлять форму.
В таблице существующий фильтр кликов исключает label/input; в дереве и объектах
выбор остаётся соседним контролом основной кнопки строки.
Сам DsCheckbox не подавляет всплытие событий глобально.

`hit` задаёт минимальную квадратную область символа, по умолчанию
`var(--ds-control-h)`. В таблице остаётся `hit={24}`, чтобы сохранить ширину колонки.
С подписью label увеличивает общую область нажатия; `hit` не задаёт ширину текста.
Hover без подписи сохраняет круглую подложку области нажатия; с подписью
сохраняется текущий hover символа. Внешние отступы задаёт родитель.

## Миграция

- Удалить публичные DsCheck, DsCheckButton, DsSelectBox, их экспорты, типы и карточки.
- Перевести таблицу, дерево, объекты и панель выбора на DsCheckbox с ariaLabel.
- Перевести формы, фильтры, превью и шаблоны на state и новый callback.
- Сохранить контракты родительских компонентов: например, onSelectAll панели
  выбора по-прежнему получает boolean, адаптация находится внутри панели.
- Обновить метаданные, документы, проверки пакета и примеров.
- На одной карточке DsCheckbox показать матрицу checkbox/radio, disabled/hover,
  примеры с подписью, описанием и без подписи. Перенести туда таблицу токенов
  DsCheck и встроить описание в основную страницу.
- Не оставлять алиасы и параллельные реализации. Исторические планы и CHANGELOG
  сохраняют старые названия как историю; актуальная документация использует новое API.

Это ломающее изменение для потребителя; добавить запись в Unreleased.
Версию пакета и релизные ветки в рамках задачи не менять, push не выполнять.

## Проверка

Проверить переходы всех состояний, callback, disabled, смешанный DOM-state,
доступные имена и описание. Проверить Space, стрелки радио, отсутствие
переключения по Enter и видимый фокус. Выбор строки не запускает открытие,
а выбор группы не раскрывает её. Проверить сохранение 24 px в таблице.

Запустить npm test и браузерные проверки затронутых сценариев в
DEFAULT/light/cozy, DEFAULT/dark/compact, RED2/light/cozy, RED2/dark/compact.
Проверить экспорт нового компонента и отсутствие удалённых публичных имён,
включая декларации типов и сборку каталога.
