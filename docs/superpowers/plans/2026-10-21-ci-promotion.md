# CI isolation and verified artifact promotion

**Goal:** ускорить проверки и релиз без исключения существующих контрактов.

**Architecture:** одна сборка передаётся независимым заданиям components,
catalogue, raster и angular. Каталог использует два worker; растровые сравнения
и Angular остаются изолированными. Успешный develop сохраняет пакет с хешами
файлов и отпечатком Git-исходников. Master принимает его только из успешного
push-workflow develop с совпадающим содержимым и исходным SHA в своей истории.
Разрешены лишь изменения CHANGELOG и полей версии package/package-lock.
При отсутствии или истечении артефакта выполняется полный набор проверок.

**Tech Stack:** Node 22, Playwright, GitHub Actions artifact API, npm staging.

## Tasks

- [x] Ожидание адаптации iframe после изменения viewport, включая отрицательный
  сценарий постоянного overflow.
- [x] Группы verify без пропуска тестов; два worker каталога и отдельный raster.
  Растровые ресурсы отдаются через общий HTTP/fixture resolver без TCP-сокетов,
  чтобы большие серии не исчерпывали сетевые буферы Windows.
- [x] Отпечаток исходников, проверка целостности пакета, поиск подходящего
  успешного develop run, безопасная подстановка релизных метаданных.
- [x] Независимые CI jobs, сохранение проверенного артефакта, promotion master
  с полной проверкой в качестве fallback; публикация только после всех gates.
- [x] Обновление документации и контрактных тестов CI; полный локальный verify.

## Validation

Тесты отклоняют изменение исходников, workflow, зависимостей, подмену артефакта,
неуспешный или чужой run, отсутствие предка и изменение полей manifest кроме
версии. Проверяются допустимые release notes/version-only изменения и fallback.
Полный verify сохраняет прежний набор, включая tarball и три браузера.

Локальная проверка завершена: полный verify прошёл, включая 205 основных
браузерных тестов (13,9 минуты), tarball и 12 проверок Chromium/Firefox/WebKit.
Отдельно прошли 11 raster-тестов, повторения iframe-тестов и components-группа
в чистой копии с передачей только общего build-артефакта. Actionlint ошибок
не обнаружил. Работа workflow и длительность на GitHub требуют первого CI run;
изменения ещё не отправлены.
