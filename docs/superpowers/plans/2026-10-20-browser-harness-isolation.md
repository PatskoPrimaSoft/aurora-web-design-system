# Подготовка и изоляция браузерного каталога

Цель: одна сборка каталога на запуск Playwright, отсутствие записи браузерных
сценариев в рабочие исходники и `site/`, сохранение существующих проверок.

Решение: global setup создаёт уникальный каталог внутри `.tmp/migration/`,
копирует необходимые исходники и собирает из них каталог. Рабочие процессы
получают путь через переменную окружения. Чтение карточек не запускает сборку.
Старый эталон готовится один раз в этой же изолированной области.
Отдельный тест изменения превью получает копию готового каталога.
Тесты dev-сервера сохраняют свои маленькие независимые фикстуры.

- [x] Добавить управление снимком и тесты независимости копий, контроля изменений
  и безопасной очистки. Подключить setup к обеим конфигурациям Playwright.
- [x] Перевести сценарии чтения на готовый каталог; убрать повторные сборки.
  Перевести визуальные сравнения на отдельные исходники/копии.
- [x] Проверить отсутствие мутаций общего снимка при teardown, обновить документацию
  и CHANGELOG. Сохранить последовательный запуск по умолчанию; отдельно проверить
  совместный запуск независимых сценариев несколькими workers.
- [x] Выполнить целевые проверки, затем полный verify; записать результат и время.

Проверки: две копии не разделяют изменяемые файлы; изменения обнаруживаются
даже при добавлении/удалении файла; очистка не выходит из выделенного каталога;
отдельный browser-spec запускается без прежнего `site/`; визуальная отрицательная
проверка не меняет каталог других сценариев; все существующие тесты сохраняются.

Результаты:
- Проверка копирования, обнаружения изменений и границ очистки прошла.
- Одиночный spec прошёл через самостоятельную подготовку Playwright.
- 11 целевых тестов с двумя workers прошли, включая изменение превью и сравнение
  исходников с поставкой; общие файлы не изменились.
- Полный verify завершился с кодом 0: 202 браузерных теста, tarball-потребители
  и 12 тестов Chromium/Firefox/WebKit прошли.
- Основной браузерный набор: 28,5 минуты против 39,6 минуты в предыдущем запуске
  на этой машине, около 28% быстрее при одном worker и прежних 202 тестах.
  Полный verify занял 35,4 минуты. Это измерение двух локальных запусков,
  не гарантированное время CI.
- Контрольные суммы общих исходников, каталога и старого эталона совпали
  после браузерных тестов; временные снимки удалены.

Независимое ревью не выявило блокирующих замечаний. Некоторые сценарии читают
ожидаемые значения и список примеров из рабочих исходников; запись туда исключена,
но редактирование исходников во время запуска может изменить эти ожидания.
