# Подготовка npm-пакета вне корня

Цель: собирать готовую структуру пакета в `.tmp/package/`, сохранив exports,
публичные пути, шрифты, документацию и совместимые исходные Angular-входы.
Корень содержит манифест разработки; CI и проверки упаковывают staging.

- [x] Добавить регрессионные проверки чистого корня и обновления staging.
- [x] Отделить сборку каталога от копий npm; собирать staging после всех выходов.
- [x] Перевести tarball-потребителей, команды упаковки и CI на staging.
- [x] Обновить инструкции; убрать прежние игнорируемые копии.
- [x] Выполнить целевые проверки и полный verify.

Риски: URL шрифтов в CSS, pinned baseline, относительные импорты линтера,
обновление allowlist, рекурсивные lifecycle hooks, неполный пакет при упаковке
из корня, устаревшие файлы при повторной сборке. Исторический эталон не меняется.

Проверка 2026-10-21: регрессионный clean-build сначала упал на отсутствии
staging, затем прошёл. Прошли deterministic-build с проверкой удаления старых
файлов, check-pack, команда упаковки staging и отклонение обычной упаковки
корня. Исправлены проверки URL шрифтов и разрешение импорта копируемого
ECharts-примера; компилятор Angular использует каноническую декларацию theme bridge.

Полный verify завершился с кодом 0 за 1979,9 с: 203 основных браузерных теста,
четыре независимых offline/AOT Angular-потребителя с поведением кнопки в 19/20,
tarball-приёмка и 12 тестов Chromium/Firefox/WebKit. Общие снимки не изменились.

Во время промежуточных прогонов дважды возник редкий сбой глобальных React/
ReactDOM в неизменённом историческом архиве. Причина не установлена: отдельный
цикл из 600 загрузок и повторный штатный тест прошли. Harness теперь сохраняет
стек JavaScript-ошибок и requestfailed. Повторные попытки не добавлялись,
условия сравнения не ослаблялись; итоговый полный прогон прошёл без сбоя.
