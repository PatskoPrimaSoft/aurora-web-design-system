# Смена типографической системы

Ранее интерфейс использовал размеры из диапазона 9–32px и стек
`Helvetica Neue` с системными подстановками. Выбор размера в отдельных
местах и зависимость от установленных шрифтов затрудняли согласование
экранов между платформами.

Текущая система поставляет Inter Tight для интерфейса и JetBrains Mono
для телеметрии. Девять семантических ролей используют семь размеров:
11, 12, 13, 14, 16, 20 и 30px. Роли различаются также весом,
межстрочным интервалом и назначением.

## Правила переноса

- Подключите стили пакета, чтобы использовать поставляемые шрифты.
- Заменяйте локальные размеры ролями по назначению текста, а не по близости кегля.
- Для display и title задавайте `--ds-tracking-tight`, для eyebrow —
  `--ds-tracking-eyebrow` и верхний регистр. Трекинг не входит в CSS-свойство `font`.
- Не используйте размеры 18 и 24px из примитивной шкалы как самостоятельные роли.
- Проверьте кириллицу, переносы, числовые столбцы и обе плотности интерфейса.
- Сохраняйте доступ к полному тексту, если ограничение ширины требует усечения.
