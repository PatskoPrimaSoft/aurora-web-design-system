# Презентация для руководства

Дека о дизайн-системе Aurora простым языком: было / стало, любой клиент, эффект, статус, решения. Читатель — руководство, а не разработчики: это рассказ о системе, а не её часть. Токены, компоненты и правила из этой папки не берутся.

| Файл | Зачем |
|---|---|
| `LeadershipDeck.dc.html` | сама дека, точка входа |
| `deck-stage.js`, `support.js` | движок показа слайдов |
| `ds-base.js` | подгружает стили и бандл системы в деку |

**Как есть она не откроется.** `ds-base.js` грузит файлы в раскладке до переноса — `tokens/*.css`, `styles.css`, `_ds_bundle.js`, — а в этом артефакте стили системы теперь `components/bundle.css` и генерируемый `tokens.css`, бандл — `components/bundle.js`. Папка хранится как есть, до отдельного переноса деки; при переносе поправьте в `ds-base.js` список файлов и строку `base`.

Цифры и статусы в деке — на момент её создания. Перед показом сверяйте их с актуальными карточками компонентов и `CHANGELOG.md`.
