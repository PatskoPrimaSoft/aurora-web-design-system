# Дизайн-система

Общие визуальные основы, React-компоненты, примеры и каталог находятся здесь.
Angular-компоненты используют эти основы и разрабатываются в
[ng-ui-kit](../ng-ui-kit/README.md).

| Директория | Назначение |
| --- | --- |
| `tokens/` | Канонические токены и типографика |
| `styles/` | Общие стили контролов, движения и иконок |
| `fonts/`, `assets/` | Шрифты и ресурсы примеров |
| `components/` | React-компоненты, контракты, документация и живые примеры |
| `catalog/` | Оболочка каталога и общие шаблоны примеров |
| `templates/` | Шаблоны подключения и совместимые адаптеры |
| `docs/` | Правила применения, токенов и оформления страниц |

Команды запускаются из корня репозитория:

```sh
mise exec -- npm run dev
mise exec -- npm run build
mise exec -- npm run verify
```

Общие инструменты, проверки поставки, npm-зависимости и CI находятся в корне.
Сборка создаёт `dist/`, `site/` и копии для прежних путей npm-пакета
(`components/src/`, `fonts/`, `assets/fonts/`, `templates/angular/` и руководства).
Эти копии не редактируются и не хранятся в Git.
