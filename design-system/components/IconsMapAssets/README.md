# Маркеры и значки карты

## Правила применения

У файлов глифов нет собственного цвета — OpenLayers умножает их на цвет стиля, поэтому один и тот же файл выглядит синим `ds-map-point` (#2b8cf7, одинаковый во всех темах и режимах) для обычной точки, зелёным `#008000` для начала смены и красным `#ff0000` для конца смены, а необязательная текстовая подпись — тем же цветом. Белый диск под ними (`ds-map-ground`) — стиль окружности, а не часть ассета: никогда не запекайте фон в файл глифа. Пины во втором ряду уже содержат свой цвет и ставятся без диска; собственные конечные точки трека живут в [Трек на карте](../MapTrack/README.md).
