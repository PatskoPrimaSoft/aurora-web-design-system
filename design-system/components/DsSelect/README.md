## Правила применения

- Используйте для выбора одного или нескольких значений, когда раскрытый список должен следовать оформлению системы. Для нативного выбора остаётся `DsField as="select"`. Для действий используйте `DsMenu`.
- `multiple` включает выбор нескольких значений. `value` и `defaultValue` — массивы строк, `onChange(values, options)` получает полный новый выбор; пустое состояние — `[]`. Не меняйте режим после монтирования.
- В мультивыборе пункты переключаются по клику, Enter или Space, список остаётся открытым. Поиск и его фокус сохраняются. Tab, Escape и Alt+↑ закрывают список без дополнительного выбора; уже сделанный выбор сохраняется.
- Выбранные значения показаны удаляемыми DsChip внутри поля и остаются видимыми в списке с чекбоксами. Чипы переносятся на следующую строку; Backspace на закрытом поле удаляет последнее значение, Delete при `clearable` очищает весь выбор. Кнопки удаления доступны с клавиатуры.
- В мультивыборе `name` передаёт каждое значение под одним именем: читайте `FormData.getAll(name)`. `required` требует хотя бы один выбранный вариант; `disabled` исключает все значения из формы. Сброс неуправляемого поля восстанавливает исходный массив.
- `searchable` добавляет поиск в раскрытом списке: фильтрация по вхождению текста без учёта регистра; произвольное значение ввести нельзя. Escape отменяет выбор и возвращает фокус на поле.
- `clearable` позволяет вернуть пустое значение: кнопка «Очистить выбор» или Delete/Backspace на закрытом поле. `onChange('', null)` сообщает очистку одного значения; в режиме `multiple` — `onChange([], [])`. Не включайте очистку для обязательного выбора без продуктовой необходимости.
- `loading` сохраняет выбранное значение, показывает индикатор и временно запрещает выбор вариантов. Данные загружает приложение; пустой список и отсутствие совпадений отличаются от загрузки.
- Группы задаются как `{ label, options }`. Группируйте все варианты по понятным категориям; избегайте групп из одного пункта. Заголовки не выбираются.
- Подпись остаётся видимой; placeholder её не заменяет. Порядок вариантов задаёт приложение по смыслу, частоте выбора или числам, без автоматической сортировки компонентом.
- Названия отображаются в одну строку; полный обрезанный текст показывается при наведении и клавиатурном фокусе. Выбранность отмечается заливкой и галочкой, наведение — заливкой, клавиатурный активный пункт — рамкой.
- У каждого варианта должны быть непустое уникальное `value` и короткий текст `label`. Пустая строка означает отсутствие выбора. Вариант с `disabled` виден, но его нельзя выбрать.
- Для управляемого компонента передайте `value` и обновляйте его в `onChange`. Для неуправляемого используйте `defaultValue`; сброс формы восстанавливает его. Не передавайте оба одновременно.
- Видимая подпись задаёт доступное имя. Без `label` передайте `aria-label` или `aria-labelledby`. Дополнительный `aria-describedby` объединяется с подсказкой или ошибкой. `ref` указывает на кнопку combobox; `onBlur` сообщает выход из всего контрола, включая поиск.
- Стрелки раскрывают список и перемещают активный пункт; Home/End — к первому/последнему, Page Up/Page Down — на десять пунктов. Недоступные варианты пропускаются. Ввод букв ищет по началу названия; повтор одной буквы перебирает совпадения.
- В одиночном выборе Enter, Space и Tab подтверждают активный вариант. Tab затем перемещает фокус дальше. Escape, повторный клик по полю и клик вне списка закрывают его без изменения значения. Без поиска фокус остаётся на контроле; с `searchable` переходит в поиск, после выбора или Escape возвращается на поле.
- `name` включает значение в данные формы. `required` использует нативную проверку формы: при пустом выборе выделяется поле и к нему переходит фокус. Для собственной проверки с `noValidate` передайте `error` и управляйте фокусом через ref.
- `disabled` блокирует раскрытие, исключает контрол из Tab и данных формы. Причину недоступности показывайте в `hint`.
- Список ограничивается `maxHeight` и доступным местом экрана; при необходимости раскрывается вверх и прокручивается. Верхний слой снимает обрезание внутри панели или диалога.
- Это выбор по имеющимся вариантам: ввода произвольного текста нет. Для длинных списков включайте `searchable`.

## Пример кода

```jsx
import { useState } from 'react';
import { DsSelect } from '@primasoftllc/design-system';

function VehicleGroup() {
  const [group, setGroup] = useState('trucks');

  return (
    <DsSelect
      label="Группа объектов"
      name="group"
      value={group}
      onChange={setGroup}
      options={[
        { value: 'trucks', label: 'Грузовики' },
        { value: 'vans', label: 'Фургоны' },
        { value: 'archive', label: 'Архивные', disabled: true },
      ]}
    />
  );
}
```


```jsx
const [groups, setGroups] = useState(['trucks']);

<DsSelect
  label="Группы для отчёта"
  name="groups"
  multiple
  searchable
  clearable
  value={groups}
  onChange={setGroups}
  options={[
    { value: 'trucks', label: 'Грузовики' },
    { value: 'vans', label: 'Фургоны' },
  ]}
/>
// При отправке формы: new FormData(form).getAll('groups')
```
