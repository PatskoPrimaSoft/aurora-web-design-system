## Правила применения

- Показывайте тост как краткую обратную связь после действия. Сообщение, которое должно оставаться доступным на странице, оформляйте через DsBanner.
- Используйте одно короткое действие, обычно «Отменить». Не размещайте в тосте форму или несколько равнозначных действий.
- Размещайте уведомления в DsToastStack на уровне страницы. Новые сообщения добавляйте в конец списка; позиция стека задаётся через position. Избегайте накопления уведомлений на весь экран. В модальном сценарии размещайте стек внутри DsDialog, чтобы его действия оставались в области клавиатурного фокуса диалога.
- Родитель управляет появлением и удалением тоста. onClose вызывается кнопкой закрытия или таймером — родитель должен убрать сообщение из состояния. Для корректной анимации удаления в стеке задавайте тостам стабильные key.
- Автозакрытие выключено по умолчанию. Для простого подтверждения можно задать autoDismiss в ms: минимальное время — 8000 ms. Наведение мыши и фокус внутри приостанавливают таймер, после ухода продолжается оставшееся время. warning и danger автоматически не закрываются. Для важного действия, которое нельзя пропустить, оставляйте ручное закрытие.
- Коротко объясняйте результат; для ошибки предлагайте следующий шаг. Длинное объяснение размещайте на странице или в DsBanner. На узком экране действие переносится под текст.
- Тост не переносит фокус на себя. Действие и закрытие доступны клавишей Tab и активируются Enter или Space. Если удаляется тост с фокусом внутри, потребитель возвращает фокус на исходное действие или соседнее уведомление.
- По умолчанию сообщение объявляется через status. Для срочного сообщения задайте announcement="assertive", для статичного примера — "off". Цвет tone не определяет срочность. Не дублируйте сообщение во второй live-области.
- Инверсная поверхность и статусные цвета иконок назначаются компонентом; не подставляйте обычные статусные цвета для светлого фона.

## Пример кода

```jsx
import { useState } from 'react';
import { DsButton, DsToast, DsToastStack } from '@primasoftllc/design-system';
import '@primasoftllc/design-system/styles.css';

export function SaveSettings() {
  const [saved, setSaved] = useState(false);
  return <>
    <DsButton onClick={() => setSaved(true)}>Сохранить настройки</DsButton>
    <DsToastStack>
      {saved && <DsToast tone="success" onClose={() => setSaved(false)}>
        Настройки сохранены.
      </DsToast>}
    </DsToastStack>
  </>;
}
```
