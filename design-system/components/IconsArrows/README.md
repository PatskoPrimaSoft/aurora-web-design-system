# Стрелки направления

## Правила применения

**Как это нарисовано.** Стрелка — это украшение линии, а не графический ассет: правильная фигура из 3 точек, радиус 6, залита собственным цветом трека и обведена белым в 1 px, чтобы читаться там, где трек пересекает обводку магистрали. Поворот берётся из азимута сегмента, шаг — из вида, см. [Трек на карте](../MapTrack/README.md).
