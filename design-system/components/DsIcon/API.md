## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-icon` | Размер `md` (по умолчанию), в том числе внутри контролов |
| `ds-icon-xs` | Размер `xs` для вспомогательных символов |
| `ds-icon-sm` | Размер `sm` в плотных строках |
| `ds-icon-lg` | Размер `lg` отдельной иконки |

Цвет иконки наследуется от родителя; собственного цветового токена у DsIcon нет.
