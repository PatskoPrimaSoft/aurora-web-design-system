## Правила применения

- Показывает статус или значимый атрибут объекта: «Движение», «Нет связи», «Черновик», «Pro». Для количества уведомлений используйте числовой счётчик, для выбора и удаления значений — `DsChip`.
- Тон передаёт смысл статуса и не меняет его между брендами и светлым/тёмным режимами. Текст обязателен по смыслу: цвет и точка только дополняют его.
- `solid` — сплошная заливка для цветного фона или карты, где тинт недостаточно отделяется от поверхности.
- `dot` предпочтительнее иконки для состояния связи.
- Компонент неинтерактивный: не получает фокус и не обрабатывает нажатия. Если статус изменился, оповещение об этом организует родитель.

## Пример кода

```jsx
import { DsLozenge } from '@primasoftllc/design-system';

export function ConnectionStatus() {
  return <DsLozenge tone="danger" dot>Нет связи</DsLozenge>;
}
```
