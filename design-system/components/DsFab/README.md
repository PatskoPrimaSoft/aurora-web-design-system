## Правила применения

- Используйте один FAB для главного действия области. Сопутствующие действия размещайте в обычной панели инструментов.
- Для важного или неоднозначного действия предпочитайте `extended` с подписью: один плюс не объясняет, что именно будет добавлено. Круглый вариант подходит для узнаваемого действия при ограниченном месте.
- Всегда задавайте короткий понятный `label`: он обязателен в типах, служит доступным названием и подсказкой, а при `extended` отображается рядом с иконкой.
- `primary` выделяет основное действие, `accent` добавляет цветовой акцент, `surface` использует нейтральную поверхность текущей темы.
- Для круглой кнопки подсказка появляется при наведении мышью и фокусе с клавиатуры. Escape закрывает подсказку; при открытой подсказке событие не закрывает внешний слой. У расширенной кнопки подсказка нужна только для сокращённой подписи.
- Расширенная кнопка ограничена шириной родителя: длинная подпись сокращается многоточием, иконка сохраняется, доступное название остаётся полным. Предпочитайте короткие подписи.
- `loading` показывает спиннер без изменения размеров и тона, сохраняет фокус и объявляет `aria-busy` и `aria-disabled`. Повторное действие и отправка формы блокируются. Родитель управляет загрузкой, сообщает результат и обрабатывает ошибку; для стабильной ширины сохраняйте исходную подпись.
- Стандартные атрибуты HTML-кнопки и обработчики событий поддерживаются в типах и передаются в DOM. По умолчанию `type="button"`.
- Размеры `sm`, `md` и `lg` — 40, 48 и 56 px. Они не меняются с плотностью интерфейса.
- Размещение и отступы задаёт родитель. Оставляйте место, чтобы кнопка не перекрывала важное содержимое и другие элементы управления.
- `disabled` блокирует действие и исключает кнопку из последовательности Tab. Причину недоступности объясняйте видимым текстом рядом.
- Кнопка активируется Enter и Space; клавиатурный фокус обозначается общим кольцом. Она выполняет действие, для перехода используйте ссылку.

## Пример кода

```jsx
import { useState } from 'react';
import { DsFab } from '@primasoftllc/design-system';

export function Objects() {
  const [count, setCount] = useState(0);

  return (
    <div style={{ position: 'relative', minHeight: 200, padding: '16px 16px 88px' }}>
      <p role="status">Объектов: {count}</p>
      <div style={{ position: 'absolute', right: 16, bottom: 16 }}>
        <DsFab
          icon="add"
          label="Добавить объект"
          extended
          onClick={() => setCount(value => value + 1)}
        />
      </div>
    </div>
  );
}
```
