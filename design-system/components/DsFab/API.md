## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-brand`, `ds-on-brand` | Заливка и содержимое primary |
| `ds-accent`, `ds-accent-on` | Заливка и содержимое accent |
| `ds-surface`, `ds-fg`, `ds-border` | Заливка, содержимое и граница surface |
| `ds-surface-hover`, `ds-surface-active` | Фон surface при наведении и нажатии |
| `ds-overlay-hover`, `ds-overlay-press` | Оверлей цвета содержимого для primary и accent при наведении и нажатии |
| `ds-surface-disabled`, `ds-fg-disabled` | Заливка и содержимое недоступной кнопки |
| `ds-shadow-md`, `ds-shadow-lg` | Тень обычной кнопки и при наведении; у недоступной кнопки тени нет |
| `ds-radius-circle`, `ds-radius-pill` | Круглая форма и форма расширенной кнопки |
| `ds-gap-sm` | Интервал между иконкой и подписью |
| `ds-type-body-strong` | Шрифт подписи |
| `ds-focus-width`, `ds-focus-color`, `ds-focus-offset` | Общее кольцо клавиатурного фокуса |
| `ds-transition-control` | Плавность изменения оформления |
| `ds-surface-inverse`, `ds-fg-on-inverse` | Фон и текст подсказки |
| `ds-pad-tight`, `ds-pad-sm`, `ds-radius-sm`, `ds-type-caption`, `ds-shadow-sm` | Отступы, скругление, шрифт и тень подсказки |
