## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-field-h` | Высота общей оболочки сегментов |
| `ds-surface`, `ds-fg` | Заливка и текст доступного поля |
| `ds-surface-disabled`, `ds-fg-disabled` | Заливка и значения недоступного поля |
| `ds-border-width`, `ds-border-field`, `ds-radius-md` | Толщина, цвет границы и скругление оболочки |
| `ds-border-field-hover` | Граница оболочки при наведении |
| `ds-brand` | Граница оболочки при фокусе внутри |
| `ds-focus-width`, `ds-focus-color`, `ds-focus-offset` | Кольцо фокуса общей оболочки |
| `ds-danger-solid`, `ds-danger-fg` | Граница ошибки и её пояснение |
| `ds-warning-solid`, `ds-warning-fg` | Граница предупреждения и его пояснение |
| `ds-type-mono` | Типографика числовых значений |
| `ds-type-caption`, `ds-weight-medium`, `ds-fg-muted` | Типографика и цвет подписи поля |
| `ds-fg-subtle` | Единицы, разделитель, иконка и обычная подсказка |
| `ds-icon-sm` | Размер иконки длительности |
| `ds-transition-control` | Плавность изменения оформления оболочки |
