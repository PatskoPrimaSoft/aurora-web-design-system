## Правила применения

- Используйте для длительности события или интервала. Для времени суток подходит `DsField type="time"`.
- Компонент управляемый: храните `value` в состоянии и обновляйте его через `onChange`. Части `d`, `h`, `m` — строки; пустая строка сохраняет незаполненный сегмент.
- Ввод оставляет только цифры: до трёх в днях и до двух в часах и минутах. Компонент не проверяет диапазоны и не переносит лишние минуты в часы. Проверку и преобразование в общее количество минут выполняет приложение.
- `showDays={false}` скрывает сегмент дней, сохраняя `d` в значении. При расчёте интервала явно решите, учитывать ли скрытые дни.
- При одновременной передаче пояснений приоритет: `error`, затем `warning`, затем `hint`.
- Каждый сегмент доступен через Tab. Названия и сокращения единиц берутся из `DsStringsProvider`; поле `label` задаёт потребитель.
- `width` задаёт ширину внешнего контейнера, включая пояснение; оболочка ввода сохраняет собственную ширину.

## Пример кода

```jsx
import { useState } from 'react';
import { DsDuration } from '@primasoftllc/design-system';

function ParkingDuration() {
  const [duration, setDuration] = useState({ d: '0', h: '2', m: '30' });

  return (
    <DsDuration
      label="Стоянка дольше"
      value={duration}
      onChange={setDuration}
      hint="Укажите минимальную длительность стоянки."
    />
  );
}
```
