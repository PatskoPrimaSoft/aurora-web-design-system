## Правила применения

- Назовите задачу поля: «Начало смены» вместо общей подписи «Значение». Связанная подпись создаётся автоматически; без видимой подписи передайте `aria-label`.
- Aurora оформляет поле, фокус, подсказку и ошибку. Ввод с клавиатуры и встроенный календарь/выбор времени обеспечивает браузер; их оформление, формат и язык зависят от браузера и системы. `lang` передаётся нативному input, но не гарантирует формат системного календаря.
- Значение и границы передаются строками `HH:mm`; пустая строка очищает поле. Время не задаёт длительность. Для нового ввода длительности используйте числовые поля с явными единицами; существующий `DsDuration` помечен устаревшим. Часовой пояс расписания поясняйте рядом; компонент не выбирает дату и не пересчитывает время.
- `required`, `min`, `max` и `step` работают через нативную проверку формы, включая ручной ввод. Шаг измеряется в секундах, по умолчанию 60; при шаге менее минуты значение может содержать секунды. Пустое необязательное поле допустимо.
- Ошибка показывается после ухода из поля либо попытки отправки формы. После исправления она снимается. Собственная `error` показывается сразу и блокирует отправку; очищать её должен код приложения. Сообщения Aurora переводятся через `DsStringsProvider`.
- `onChange(value, event)` получает строку. Используйте `value` с обработчиком для управляемого поля либо `defaultValue` для неуправляемого. `form.reset()` восстанавливает неуправляемое значение; управляемое состояние сбрасывайте в `onReset` формы.
- `ref` указывает на input: можно перевести фокус, проверить `validity` или вызвать `showPicker()` из разрешённого браузером пользовательского действия. Tab переводит фокус, остальные клавиши внутри поля определяет браузер. `readOnly` сохраняет фокус и значение в FormData; `disabled` исключает поле из Tab и FormData.
- Для периода используйте `DsDateRangePicker`: он связывает две границы и проверяет их порядок.

## Пример кода

Управляемое поле; `value` сохраняется в формате HH:mm.

```jsx
import { useState } from 'react';
import { DsTimePicker } from '@primasoftllc/design-system';

export function Example() {
  const [value, setValue] = useState('09:00');
  return <div style={{display:'flex',flexDirection:'column',gap:16}}>
    <DsTimePicker label="Начало смены" value={value} onChange={setValue} hint="Время в часовом поясе расписания: Europe/Minsk."/>
    <output aria-live="polite">Выбрано: {value || 'не указано'}</output>
  </div>;
}
```
