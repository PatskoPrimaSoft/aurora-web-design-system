## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-fg` | Цвет заголовка |
| `ds-fg-muted` | Цвет пояснения |
| `ds-fg-subtle` | Нейтральная иконка |
| `ds-info-solid`, `ds-warning-solid`, `ds-danger-solid` | Иконка соответствующего тона |
| `ds-type-section` | Заголовок обычного размера |
| `ds-type-body-strong` | Заголовок компактного варианта |
| `ds-type-body` | Пояснение |
| `ds-gap-sm-plus` | Вертикальные интервалы обычного варианта |
| `ds-gap-sm` | Интервалы компактного варианта и между действиями |
| `ds-pad-xl`, `ds-pad-lg` | Вертикальные и горизонтальные отступы обычного варианта |
| `ds-pad-lg`, `ds-pad-md` | Вертикальные и горизонтальные отступы компактного варианта |

Действия оформляются токенами переданных компонентов, например `DsButton`.
