## Правила применения

- Размещайте в области, где ожидались данные: это может быть целый раздел страницы, таблица, панель или дерево. `size="sm"` подходит для узкой панели.
- Различайте отсутствие результатов фильтра, отсутствие первых данных и ошибку запроса. Заголовок говорит, чего нет; описание объясняет причину и следующий шаг.
- Предлагайте конкретное действие: «Сбросить фильтры», «Добавить объект», «Повторить запрос». Если пользователь не может исправить ситуацию сам, объясните, к кому обратиться, без бесполезной кнопки.
- `tone="danger"` обозначает ошибку, `info` помогает начать работу, `warning` — ограничение. Текст должен объяснять ситуацию независимо от цвета и иконки.
- Первичная загрузка — не пустое состояние: пока идёт запрос, используйте `DsSkeleton`. При повторе после ошибки можно сохранить объяснение и кнопку с `loading`: она блокирует повторный запуск и сохраняет фокус. Сообщайте о ходе запроса, а после успеха показывайте данные. `DsBanner` поясняет существующее содержимое, а `DsEmptyState` заменяет отсутствующее.
- `action` — основное действие, `secondary` — необязательное дополнительное. Оба принимают готовые элементы; доступны также дочерние элементы с `slot="action"` и `slot="secondary"`.
- Кнопки доступны через Tab и активируются Enter или Space. Когда действие заменяет пустое состояние содержимым, родитель переносит фокус в появившуюся область.
- `headingLevel` задаёт уровень заголовка в структуре страницы, не меняя размер текста. По умолчанию `h2`; `none` выводит обычный текст.
- Статичные состояния используют `announcement="off"`. Для обычного динамического результата выбирайте `polite`, для срочного — `assertive`. Не дублируйте объявления дополнительной live-областью.
- Иконка декоративная и не заменяет объяснение. `icon={null}` убирает её, например в тесной панели.
- Оставляйте одно основное действие. Создание первого объекта может быть брендовой кнопкой; дополнительное действие должно быть спокойнее, справка — ссылкой с понятной подписью.
- Длинные слова и ссылки переносятся, действия переходят на следующую строку. Подписи кнопок сохраняйте короткими; DsButton сокращает слишком длинную подпись многоточием.

## Пример кода

```jsx
import { useEffect, useRef, useState } from 'react';
import { DsButton, DsEmptyState } from '@primasoftllc/design-system';
import '@primasoftllc/design-system/styles.css';

export function Objects() {
  const [filtered, setFiltered] = useState(true);
  const result = useRef(null);

  useEffect(() => {
    if (!filtered) result.current.focus();
  }, [filtered]);

  return filtered ? (
    <DsEmptyState
      icon="filter_alt"
      title="Нет объектов по заданным фильтрам"
      description="Сбросьте фильтры, чтобы увидеть все объекты."
      action={<DsButton tone="secondary" onClick={() => setFiltered(false)}>Сбросить фильтры</DsButton>}
    />
  ) : (
    <div ref={result} tabIndex={-1}>Найдено 12 объектов.</div>
  );
}
```
