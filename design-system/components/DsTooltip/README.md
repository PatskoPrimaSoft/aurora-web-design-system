## Правила применения

- Подсказка дополняет кнопку или ссылку коротким текстом: например, объясняет сокращение или менее очевидное действие. У `DsIconButton` она уже встроена.
- Важные условия, ошибки и причины недоступности показывайте постоянно рядом с контролом. Подсказка не заменяет доступное имя и плохо обнаруживается на сенсорном экране.
- Передавайте один интерактивный элемент: `DsButton`, нативную кнопку или ссылку. Собственный компонент должен передавать ARIA-атрибуты и обработчики фокуса, указателя и нажатия DOM-элементу. Его существующий ref сохраняется.
- `content` принимает только текст. Для ссылок, изображений, кнопок и полей используйте `DsPopover`; для обязательной задачи — `DsDialog`. Не повторяйте очевидную видимую подпись кнопки.
- Наведение мыши и клавиатурный фокус раскрывают подсказку. Указатель можно перевести на её текст. Escape или нажатие на действие закрывают её; после ухода фокуса и указателя она также исчезает.
- Существующее `aria-describedby` сохраняется. На недоступном или загружаемом элементе подсказка не открывается; отдельный `disabled` отключает её явно.
- `placement` задаёт предпочтительную сторону. Размещение учитывает края окна, прокрутку и размеры содержимого. Тема и плотность наследуются от места использования.
- В браузерах с Popover API слой не обрезается контейнером. Без него используется фиксированное размещение: избегайте предков с обрезанием и `transform`. В каталоге границей служит iframe примера.

## Пример кода

```jsx
import { DsButton, DsTooltip } from '@primasoftllc/design-system';
import '@primasoftllc/design-system/styles.css';

export function Example() {
  return <DsTooltip content="Сохранить текущий набор столбцов для следующих сеансов">
    <DsButton tone="secondary">Запомнить вид</DsButton>
  </DsTooltip>;
}
```
