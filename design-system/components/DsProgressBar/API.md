## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-brand` | Полоса выполняющейся операции |
| `ds-success-solid` | Успешное завершение |
| `ds-border` | Фон полосы |
| `ds-radius-circle` | Скругление |
| `ds-type-caption` | Название и значение |
| `ds-gap-xs / ds-gap-sm` | Внутренние интервалы |
