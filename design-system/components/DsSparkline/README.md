## Правила применения

- Используйте рядом с числом в строке или ячейке; для подробного анализа нужен полноценный график.

- `null` — пропуск данных, линия разрывается.
- `series` (по умолчанию) — `--ds-series-1`; статусные тоны — только когда само направление хорошее или плохое (слив топлива, превышения).
- Без `label` спарклайн скрыт от вспомогательных технологий — правильно только если то же число уже есть в строке текстом.
- При `area={true}` шкала включает ноль, заливка идёт до нулевого уровня, в том числе при отрицательных значениях. Без заливки диапазон подстраивается под данные, чтобы показать форму тренда. В плотной таблице выключите `area`.

## Пример кода

```jsx
import { DsSparkline } from '@primasoftllc/design-system';

export function FuelTrend() {
  return (
    <DsSparkline
      data={[40, 38, 35, null, 30, 26, 24]}
      tone="danger"
      label="Уровень топлива падает"
      area={false}
    />
  );
}
```
