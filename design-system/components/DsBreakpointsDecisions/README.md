# Брейкпоинты: решения по миграции

## Когда миграцию можно считать завершённой

- Проверены переходы 719/720, 959/960 и 1139/1140px: нет наложения правил,
  обрезанных контролов и потери доступа к действиям.
- Шапки проверены с длинными именами и подписями, управление доступно с клавиатуры.
- Компоновка работает в обеих плотностях, светлом и тёмном режимах DEFAULT и RED2.
- Для каждого пункта списка указаны фактический файл приложения и результат проверки:
  исправлено, уже соответствует правилам или требуется отдельное решение.

Токены определены в `tokens/source.json` и включаются в сборку дизайн-системы.
`ViewBreakpointService` относится к приложению и не входит в React-пакет.
Подключение токенов само по себе не меняет компоновку.

## Сравнения в сервисе приложения

Сравнения `ViewBreakpointService` строгие: `more('m')` — L и XL,
`less('l')` — S и M, `equal('s')` — только S. При переносе условий
указывайте результирующий диапазон, например «L и шире», чтобы не путать
«больше M» с «M и больше».
