## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-info-bg`, `ds-success-bg`, `ds-warning-bg`, `ds-danger-bg`, `ds-neutral-bg` | Подложка сообщения соответствующего тона |
| `ds-info-fg`, `ds-success-fg`, `ds-warning-fg`, `ds-danger-fg`, `ds-neutral-fg` | Заголовок сообщения |
| `ds-info-solid`, `ds-success-solid`, `ds-warning-solid`, `ds-danger-solid`, `ds-neutral-solid` | Статусная иконка |
| `ds-fg` | Основной текст пояснения |
| `ds-pad-sm`, `ds-pad-md`, `ds-pad-tight` | Отступы обычного и компактного сообщения |
| `ds-gap-sm-plus`, `ds-gap-sm` | Интервалы между иконкой, содержимым и закрытием; между действиями |
| `ds-radius-lg` | Скругление баннера |
| `ds-icon` | Размер статусной иконки |
| `ds-type-body-strong`, `ds-type-body` | Типографика заголовка и пояснения |
| `ds-text-14`, `ds-lh-normal` | Высота области статусной иконки для выравнивания с первой строкой |
| `ds-control-h-sm`, `ds-icon-sm`, `ds-radius-md` | Размер, иконка и скругление системной кнопки закрытия |
| `ds-fg-muted`, `ds-surface-hover`, `ds-surface-active`, `ds-transition-control` | Цвет, hover/pressed и переходы DsIconButton закрытия |
| `ds-focus-width`, `ds-focus-color`, `ds-focus-offset` | Кольцо клавиатурного фокуса кнопки закрытия |
| `ds-surface-inverse`, `ds-fg-on-inverse`, `ds-type-caption`, `ds-pad-tight`, `ds-pad-sm`, `ds-radius-sm`, `ds-shadow-sm` | Оформление системной подсказки кнопки закрытия |
