## Правила применения

- Показывайте баннер рядом с содержимым, к которому относится сообщение. Он описывает условие, сохраняющееся до его устранения; краткий результат действия показывайте через `DsToast`.
- Выбирайте тон по смыслу сообщения. Срочность объявления задаётся отдельно: `announcement="off"` для статичного сообщения, `"polite"` для обычного динамического обновления, `"assertive"` для срочного изменения, требующего немедленного внимания. Не обновляйте текст без необходимости, чтобы не создавать повторные объявления.
- Выбирайте `headingLevel` по иерархии страницы; по умолчанию это `h2`. Для короткой подписи без отдельного раздела используйте `headingLevel="none"`.
- Заголовок кратко описывает условие, текст поясняет последствия и следующий шаг. В предупреждении или ошибке объясните, как продолжить работу; если исправление недоступно пользователю, укажите, чего ожидать или куда обратиться. Не обвиняйте пользователя в сбое сервиса. Заголовок пишется без точки, полные предложения в теле — с точкой.
- Передавайте действия через `actions` или дочерний элемент с `slot="actions"`. Обычно достаточно одного, максимум двух. Для изменения данных или повторного запроса используйте `DsButton tone="secondary" size="sm"`, для перехода к справке — ссылку. Подпись объясняет действие или назначение: «Повторить запрос», «О сроке хранения данных» вместо «Подробнее».
- Во время запроса задавайте кнопке `loading`, чтобы сохранить фокус и заблокировать повторный запуск. Сообщение объясняет, что выполняется; после ответа оно отражает текущее условие. Не заменяйте сфокусированную кнопку другим элементом без переноса фокуса.
- Заголовок необязателен: если короткое пояснение уже передаёт весь смысл, не повторяйте его отдельной строкой.
- `onClose` только сообщает о закрытии: родитель убирает баннер. Без обработчика кнопка закрытия не показывается. Это `DsIconButton` с системной подсказкой; `closeLabel` уточняет, какое сообщение будет скрыто. Не давайте скрывать сообщение, если оно необходимо для безопасного продолжения работы.
- После удаления баннера с находящимся внутри фокусом переведите фокус на логичный доступный элемент рядом. Кнопки действия и закрытия доступны через Tab, Enter и пробел; сам баннер не перехватывает фокус.
- Пояснение использует основной цвет текста. Длинные слова и ссылки переносятся, действия переходят на следующую строку при нехватке ширины.
- `compact` уменьшает внутренние отступы. Используйте его для коротких сообщений в плотном интерфейсе.

## Пример кода

```jsx
import { useState } from 'react';
import { DsBanner, DsButton } from '@primasoftllc/design-system';

export function ReportPeriod() {
  const [days, setDays] = useState(365);
  return (
    <>
      <p>Период отчёта: {days} дней</p>
      <DsBanner
        announcement="polite"
        tone={days > 90 ? 'warning' : 'info'}
        title={days > 90 ? 'Период длиннее срока хранения' : 'Данные за выбранный период доступны'}
        actions={days > 90 && (
          <DsButton tone="secondary" size="sm" onClick={() => setDays(7)}>
            Выбрать последние 7 дней
          </DsButton>
        )}
      >
        Срок хранения данных — 90 дней.
      </DsBanner>
    </>
  );
}
```
