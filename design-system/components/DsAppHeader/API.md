## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-header-h` | Высота шапки в выбранной плотности |
| `ds-surface`, `ds-fg-strong`, `ds-fg-muted` | Фон, название продукта и дополнительный контекст |
| `ds-border` | Разделитель шапки и содержимого |
| `ds-brand` | Подложка знака бренда |
| `ds-brand-subtle`, `ds-brand-text` | Метка окружения |
| `ds-shadow-sm` | Тень шапки после прокрутки содержимого |
