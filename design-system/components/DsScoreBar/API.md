## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-fg-strong` | Значение оценки и маркер на шкале |
| `ds-fg-muted` | Подпись шкалы |
| `ds-fg-subtle` | Единица измерения и границы диапазона |
| `ds-danger-solid`, `ds-warning-solid`, `ds-success-solid`, `ds-info-solid` | Полосы оценки и подпись выбранного диапазона |
| `ds-surface-active` | Фон шкалы при отсутствии оценки |
