## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-type-body` | Читаемые названия уровней |
| `ds-brand-text` | Ссылки на родительские страницы через DsLink |
| `ds-fg` | Текущая страница |
| `ds-fg-muted` | Разделители и уровни без страницы |
| `ds-gap-sm` | Расстояния между уровнями и разделителями |
| `ds-focus-color`, `ds-focus-width`, `ds-focus-offset` | Клавиатурный фокус ссылок |
