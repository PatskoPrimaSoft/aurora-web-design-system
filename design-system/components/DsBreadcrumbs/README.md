## Правила применения

- Показывайте путь в иерархии, а не историю посещённых страниц. Цепочка дополняет основную навигацию приложения и располагается над заголовком страницы.
- Передавайте уровни от корня к текущей странице. Предкам задавайте реальные адреса; последний пункт всегда становится текстом с `aria-current="page"`, даже если у него есть `href`.
- Названия уровней должны совпадать с названиями страниц. Для нескольких цепочек на странице задавайте разные доступные имена через `aria-label`.
- Все уровни остаются видимыми и переносятся на узком экране. Не сокращайте важные названия многоточием. Если промежуточный уровень не имеет страницы, оставьте его без `href`.
- Tab перемещает фокус между ссылками предков, Enter открывает страницу. Разделители скрыты от скринридера; текущая страница не добавляет лишнюю остановку Tab.

## Пример кода

```jsx
import { DsBreadcrumbs } from '@primasoftllc/design-system';

export function Example() {
  return (
    <DsBreadcrumbs aria-label="Положение в каталоге" items={[
      { label: 'Автопарк', href: '/fleet' },
      { label: 'Грузовые автомобили', href: '/fleet/trucks' },
      { label: 'МАЗ 5440' },
    ]}/>
  );
}
```
