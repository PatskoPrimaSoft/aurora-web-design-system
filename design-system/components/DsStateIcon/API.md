## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-state-moving`, `ds-state-parked`, `ds-state-offline`, `ds-state-invalid`, `ds-state-alarm`, `ds-state-nodata` | Цвет глифа соответствующего состояния, в том числе без диска |
| `ds-success-bg` | Диск состояния «Движение» |
| `ds-neutral-bg` | Диск состояний «Стоянка» и «Нет данных» |
| `ds-danger-bg` | Диск состояния «Нет связи» |
| `ds-info-bg` | Диск состояния «Некорректные данные» |
| `ds-warning-bg` | Диск состояния «Тревога» |
