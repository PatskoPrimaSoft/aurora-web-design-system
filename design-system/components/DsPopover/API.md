## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-surface-raised` | Поверхность панели над содержимым |
| `ds-fg` | Основной цвет содержимого |
| `ds-type-body` | Основной текст панели |
| `ds-pad-md` | Внутренние отступы панели с учётом плотности |
| `ds-border` | Тонкая граница панели |
| `ds-radius-md` | Скругление панели |
| `ds-shadow-md` | Тень панели над страницей |
| `ds-focus-width`, `ds-focus-color`, `ds-focus-offset` | Общее кольцо клавиатурного фокуса |
