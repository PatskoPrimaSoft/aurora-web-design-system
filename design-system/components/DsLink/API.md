## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-brand-text` | Доступный цвет текста ссылки на текущей поверхности |
| `ds-focus-color`, `ds-focus-width`, `ds-focus-offset` | Кольцо клавиатурного фокуса |

Типографика наследуется от окружающего текста. Подчёркивание сохраняет различимость ссылки без опоры только на цвет.
