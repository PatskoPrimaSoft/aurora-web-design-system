## Правила применения

- Используйте ссылку для перехода на страницу, к разделу или файлу. Для изменения состояния и запуска операции выбирайте `DsButton`.
- Пишите название назначения: «Настройки уведомлений» вместо «Подробнее». Ссылка внутри абзаца наследует его размер текста и остаётся подчёркнутой.
- Передавайте реальный `href`. Enter выполняет переход; Ctrl/Cmd + клик, контекстное меню и скачивание работают средствами браузера. Роутер приложения может обрабатывать переход через `onClick`, сохраняя эти возможности.
- Для `target="_blank"` компонент добавляет `noopener noreferrer`. Укажите открытие новой вкладки в тексте, если оно неожиданно для пользователя.
- Не изображайте недоступную ссылку: если назначения ещё нет, покажите обычный текст с пояснением. Длинные названия переносятся без обрезания.

## Пример кода

```jsx
import { DsLink } from '@primasoftllc/design-system';

export function Example() {
  return (
    <div>
      <DsLink href="#notifications">Настройки уведомлений</DsLink>
      <section id="notifications"><h2>Настройки уведомлений</h2></section>
    </div>
  );
}
```
