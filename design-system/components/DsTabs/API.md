## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-brand-text`, `ds-brand` | Подпись и нижний индикатор выбранной вкладки `underline` |
| `ds-fg-muted` | Подпись невыбранной вкладки внутри страницы |
| `ds-border` | Нижняя граница `underline` и рамка группы `segmented` |
| `ds-bg-sunken`, `ds-surface`, `ds-shadow-xs` | Подложка группы, заливка и тень выбранного сегмента |
| `ds-fg-strong` | Подпись выбранного сегмента |
| `ds-brand-text`, `ds-fg-muted` | Подписи выбранного и остальных разделов шапки |
| `ds-fg` | Иконка невыбранного раздела шапки |
| `ds-surface-hover`, `ds-brand` | Подложка выбранного / наведённого раздела и нижний индикатор в шапке |
| `ds-accent`, `ds-accent-on` | Фон и текст счётчика в шапке |
| `ds-header-h`, `ds-control-h-sm` | Высота навигации в шапке и кнопки сегмента |
| `ds-gap-md`, `ds-gap-sm` | Интервалы между вкладками `underline` и между иконкой и подписью |
| `ds-icon`, `ds-icon-sm` | Размер иконок обычной вкладки и сегмента |
| `ds-radius-md`, `ds-radius-pill` | Скругление группы сегментов, счётчиков и индикаторов |
| `ds-type-ui`, `ds-type-caption`, `ds-type-eyebrow` | Типографика вкладок, подписи под иконкой и счётчика |
| `ds-focus-width`, `ds-focus-color`, `ds-focus-offset` | Общее кольцо клавиатурного фокуса |
| `ds-surface-active`, `ds-fg` | Нейтральная подложка и текст счётчика внутри страницы |
| `ds-fg-strong`, `ds-border-strong` | Подпись и предварительное подчёркивание невыбранной вкладки при наведении |
| `ds-surface-hover`, `ds-surface-active` | Подложка сегмента при наведении и нажатии; подложка нажатой вкладки underline |
| `ds-surface`, `ds-fg-strong`, `ds-overlay-press` | Подложка нажатого раздела шапки: её фон с оверлеем собственных чернил |
| `ds-border-strong`, `ds-surface` | Ползунок и дорожка полосы прокрутки |
| `ds-dur-fast`, `ds-ease` | Длительность и кривая перемещения индикатора; при reduced motion длительность равна нулю |
| `ds-transition-control` | Плавность изменения оформления вкладки |
