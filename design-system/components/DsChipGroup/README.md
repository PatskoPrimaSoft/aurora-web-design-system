## Правила применения

- Объединяйте чипы одного назначения. В одной группе не смешивайте переключаемые фильтры, удаляемые значения и постоянные метки.
- Передайте `ariaLabel`, которое объясняет назначение группы. Если название важно всем пользователям, покажите его и в видимом заголовке рядом.
- `onClearAll` только запрашивает очистку: родитель снимает выбор или удаляет значения. Для группы фильтров можно уточнить подпись через `clearAllLabel="Снять выбор"`. Показывайте очистку, когда есть что сбрасывать.
- Порядок чипов сохраняется при переносе. Не добавляйте внутреннюю прокрутку и не скрывайте применённые фильтры только ради одной строки. Используйте чипы умеренно: большое количество затрудняет просмотр.
- Tab проходит по доступным действиям чипов и затем кнопке очистки; Enter и Space вызывают действие. Группа не создаёт дополнительной остановки фокуса и не перехватывает стрелки.
- После удаления или очистки родитель переводит фокус на соседний чип либо на контрол добавления значений. Пустая группа скрывается; пояснение пустого состояния при необходимости показывает родитель.

## Пример кода

```jsx
import { useRef, useState } from 'react';
import { DsButton, DsChip, DsChipGroup } from '@primasoftllc/design-system';

function SelectedGroups() {
  const [values, setValues] = useState(['Грузовики', 'Легковые']);
  const restore = useRef(null);

  function update(next) {
    setValues(next);
    restore.current?.querySelector('button')?.focus();
  }

  return (
    <>
      <span ref={restore}>
        <DsButton size="sm" tone="secondary"
          onClick={() => setValues(['Грузовики', 'Легковые'])}>
          Восстановить группы
        </DsButton>
      </span>
      <DsChipGroup ariaLabel="Выбранные группы" onClearAll={() => update([])}>
        {values.map(value => (
          <DsChip key={value} removable
            onRemove={() => update(values.filter(item => item !== value))}>
            {value}
          </DsChip>
        ))}
      </DsChipGroup>
    </>
  );
}
```
