## Правила применения

Размещайте фильтры рядом с содержимым, которое они изменяют. Заголовок таблицы используйте для сортировки. Применённое значение видно в кнопке фильтра; отдельный крестик рядом очищает весь фильтр одним нажатием. Не дублируйте те же значения чипами.

`label` задаёт подпись кнопки и доступное имя поповера. `value` — применённое значение; изменение полей меняет только внутренний черновик. В `onApply` сохраните новое значение и обновите данные. В `onClear` сбросьте значение в родителе. Если `onClear` не задан, очистка вызывает `onApply` с пустым значением: `[]` для нескольких вариантов, `{ from: null, to: null }` для диапазона, `null` для остальных типов.

У нескольких выбранных вариантов кнопка показывает первый и количество остальных, например «Движение +2». Полный выбор доступен в редакторе и доступном имени кнопки. Длинный текст сокращается многоточием. Через `formatValue(value)` можно задать формат диапазона, единицы измерения или локальную дату; это меняет только подпись, а не значение.

Для `checkbox-list` передавайте плоский список `options` или группы `{ label, options }`, как в DsSelect. Подписи групп не выбираются. Варианты из разных групп сохраняются в одном массиве строк; счётчик `count` показывается справа от названия. Нажатие на всю строку или Space меняет черновик, список остаётся открытым до применения или закрытия.

`searchable` добавляет поиск по названию для списочных типов, сохраняя группы найденных вариантов. `loading` показывает индикатор загрузки, временно блокирует выбор и применение; уже применённое значение сохраняется. Пустой список и отсутствие результатов поиска показаны отдельно. Для недоступного варианта задайте `disabled` и объясните причину через `description`. `disabled` у самого DsFilterMenu запрещает открытие и очистку.

Типы значений: текст — строка или `null`; число — число или `null`; диапазон — `{ from, to }` с пустой границей `null`; дата — строка `YYYY-MM-DD` или `null`; несколько вариантов — массив строк; один вариант — строка. Ноль и отрицательное число — заполненные значения.

`sort-by` предназначен для списков, деревьев и карточек без заголовков столбцов. Передавайте `{ key, dir }`, чтобы показать выбор поля и пары направлений. Подписи направлений задаются через `asc` и `desc` у варианта; кнопки направлений расположены вертикально. `group: true` скрывает направления для группировки. В режиме `sort-by` внешнего крестика нет. Передайте `onClear`, который возвращает исходный порядок: действие в меню будет называться «Сбросить порядок». Без `onClear` сохраняется «Очистить» с передачей пустого значения в `onApply`.

Кнопку можно открыть Enter или Space. При открытии фокус переходит на поиск, поле ввода или первый доступный вариант. Стрелки и Home/End перемещают фокус по вариантам, пропуская недоступные; Space меняет выбор. Tab переводит от списка к действиям. Escape отменяет черновик и возвращает фокус на кнопку; нажатие снаружи или уход фокуса закрывает редактор без применения. «Применить» и «Очистить» также возвращают фокус.

В диапазоне значение «От» не должно превышать «До». При ошибке «Применить» остаётся доступной: нажатие показывает сообщение у поля «До», переводит туда фокус и оставляет редактор открытым. После исправления сообщение исчезает. Одну границу можно оставить пустой. В текстовом, числовом и фильтре даты Enter применяет значение.

Поповер открывается вниз или вверх по доступному месту, подстраивается под экран и выводится в верхний слой браузера. `width` и `maxHeight` задают желаемые размеры в px; экран ограничивает их. Содержимое прокручивается, действия остаются видимыми. При использовании `trigger` передавайте доступную кнопку: обработчик открытия добавляет компонент, а её имя, выбранное значение, недоступность и ARIA-атрибуты задаёт потребитель.

## Пример кода

```jsx
import { useState } from 'react';
import { DsFilterMenu } from '@primasoftllc/design-system';

export function Example() {
  const [states, setStates] = useState([]);

  return (
    <DsFilterMenu
      label="Состояние объектов"
      type="checkbox-list"
      value={states}
      options={[
        { value: 'moving', label: 'Движение' },
        { value: 'parked', label: 'Стоянка' },
      ]}
      onApply={setStates}
      onClear={() => setStates([])}
    />
  );
}
```
