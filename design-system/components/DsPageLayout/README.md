## Правила применения

- Передавайте основное содержимое в `children`. Шапки находятся над ним, `footer` — под ним, `left` и `right` — по сторонам. Отсутствующий регион не занимает места.
- Компонент создаёт `main` и боковые `aside`: не добавляйте внутри второй `main`. Задавайте содержательные `leftLabel` и `rightLabel`, например «Объекты» и «Сведения», чтобы различать регионы и кнопки раскрытия.
- `responsive` включает адаптацию по ширине самого каркаса. Ниже `responsiveBreakpoint` или при нехватке места для `mainMinWidth` панели изначально скрыты и раскрываются кнопками в потоке страницы. Содержимое остаётся смонтированным: формы сохраняют ввод. При переходе в узкую раскладку панели закрываются, а фокус из панели переносится на её кнопку.
- Выбирайте прокрутку по задаче. `scroll="none"` оставляет её приложению и подходит обычной странице без заданной высоты. `scroll="page"` прокручивает весь каркас; `scroll="regions"` — основной и боковые регионы отдельно, сохраняя шапки и нижний регион. Для последних двух режимов родитель задаёт определённую высоту. Не добавляйте вложенную прокрутку без необходимости.
- Ссылка «К содержимому» появляется при фокусе и переводит его в основной регион. Подпись можно изменить через `skipLinkLabel`, идентификатор — через `mainId`. Отключайте `skipLink`, только если приложение уже предоставляет такой переход.
- `gap` управляет интервалами между регионами и их детьми, `padding` — внутренними отступами каркаса. Без явного `padding` его значение совпадает с `gap`: `gap={false}` подходит для карты без отступов. Отступы самого содержимого задают вложенные компоненты.
- Ширину боковых регионов можно задать числом в px или CSS-длиной; по умолчанию используются токены. Располагайте сетку содержимого внутри основного региона, чтобы её колонки не зависели от ширины панелей.
- Вместо props поддерживаются дети с `slot` или `data-slot`: `header`, `pageHeader`, `left`, `right`, `footer`. Явный prop имеет приоритет; `null` отключает регион. Заменённые и повторные слоты не попадают в основное содержимое.

## Пример кода

```jsx
import { DsAppHeader, DsPageLayout } from '@primasoftllc/design-system';

export function ObjectsPage() {
  return (
    <div style={{ height: 600 }}>
      <DsPageLayout
        responsive
        scroll="regions"
        header={<DsAppHeader product="Aurora" section="Мониторинг" user="a.ivanov" />}
        pageHeader={<header><h1>Объекты</h1></header>}
        leftLabel="Объекты"
        left={<p>Список объектов</p>}
        rightLabel="Сведения"
        right={<p>Сведения об объекте</p>}
      >
        <p>История выбранного объекта</p>
      </DsPageLayout>
    </div>
  );
}
```
