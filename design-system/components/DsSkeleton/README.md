## Правила применения

- Повторяйте примерную геометрию будущего содержимого: строки текста, аватар, изображение. Размеры и интервалы задаёт родитель.
- Используйте скелетон, когда структура содержимого известна. Для действия в кнопке используйте её `loading`, для неопределённого процесса без известной структуры — `DsSpinner`.
- При обновлении уже загруженных данных по возможности сохраняйте содержимое на месте, чтобы пользователь не терял контекст.
- Для плотных списков и рядом с движущимся содержимым можно отключить пульсацию через `animated={false}`. При системной настройке `prefers-reduced-motion` она отключается автоматически.
- Каждый блок скрыт от скринридера через `aria-hidden`. Задайте `aria-busy` области данных и одно текстовое сообщение о загрузке; не объявляйте каждый скелетон отдельно.
- Скелетон не принимает фокус. При замене его данными сохраняйте фокус на текущем элементе управления; переносите его только при необходимости продолжить сценарий.
- После завершения запроса покажите данные, `DsEmptyState` при их отсутствии или объяснение ошибки с доступным следующим шагом.

## Пример кода

```jsx
import { DsSkeleton } from '@primasoftllc/design-system';
import '@primasoftllc/design-system/styles.css';

export function UserName({ loading, name }) {
  return (
    <div>
      <div aria-busy={loading}>
        {loading ? <DsSkeleton width="70%" height={16} /> : name}
      </div>
      <span role="status">
        {loading ? 'Загрузка пользователя…' : 'Пользователь загружен.'}
      </span>
    </div>
  );
}
```
