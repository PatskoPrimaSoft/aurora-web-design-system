## Правила применения

- Используйте для последовательной задачи: импорта, экспорта или создания объекта. Для независимых разделов подходят вкладки.
- `active` — индекс текущего шага с нуля. Содержимое этапа, проверку данных и переход вперёд реализует приложение.
- По умолчанию завершёнными считаются шаги перед `active`. При возврате это состояние пересчитывается. Чтобы сохранить завершённые этапы независимо от текущего, передавайте их индексы в `completed`.
- С `onSelect` доступны текущий и завершённые шаги. `disabled` у шага запрещает переход независимо от завершённости. Остальные будущие шаги недоступны. Без `onSelect` компонент показывает прогресс обычным текстом.
- Текущий шаг всегда показывает номер, даже если входит в `completed`. Для завершения всей задачи передайте `isComplete`: все шаги получат галочки, текущего не будет. Возврат к доступным шагам остаётся возможным, если передан `onSelect`; для итогового просмотра уберите обработчик.
- Задайте `ariaLabel` по задаче, например «Импорт объектов». Положение и статус каждого шага озвучиваются через общий словарь `DsStrings`.
- Tab переводит фокус между доступными шагами; Enter или Space вызывает `onSelect`. Текущий шаг отмечен `aria-current="step"`. Hover, нажатие и клавиатурный фокус выделяют доступный шаг.
- Выбирайте короткие подписи; `hint` подходит для краткого пояснения. На узком экране длинная цепочка имеет видимую горизонтальную полосу прокрутки. Текущий шаг автоматически появляется в видимой области при переходе и изменении ширины; страница и фокус остаются на месте.
- Для длинной задачи используйте отдельный экран; в диалоге ограничивайтесь двумя–тремя шагами.

## Пример кода

```jsx
import { useState } from 'react';
import { DsButton, DsStepper } from '@primasoftllc/design-system';

const steps = [
  { id: 'file', label: 'Файл' },
  { id: 'fields', label: 'Поля', hint: 'Сопоставление' },
  { id: 'check', label: 'Проверка' },
];
const content = ['Выберите файл.', 'Сопоставьте поля.', 'Проверьте данные.'];

export function ImportSteps() {
  const [active, setActive] = useState(0);
  const [isComplete, setComplete] = useState(false);

  return (
    <div>
      <DsStepper
        ariaLabel="Импорт объектов"
        steps={steps}
        active={active}
        isComplete={isComplete}
        onSelect={isComplete ? undefined : setActive}
      />
      <p role="status">{isComplete ? 'Импорт завершён.' : content[active]}</p>
      <DsButton disabled={isComplete} onClick={() => {
        if (active < steps.length - 1) setActive(active + 1);
        else setComplete(true);
      }}>
        {active === steps.length - 1 ? 'Импортировать' : 'Далее'}
      </DsButton>
    </div>
  );
}
```
