## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-brand`, `ds-on-brand` | Заливка, граница и номер текущего шага |
| `ds-brand-text` | Подпись доступного текущего шага |
| `ds-success-solid`, `ds-on-solid` | Заливка, граница и галочка завершённого шага |
| `ds-success-line` | Соединитель после завершённого шага |
| `ds-border-strong`, `ds-border` | Граница будущего шага и обычный соединитель |
| `ds-fg` | Подпись завершённого шага |
| `ds-fg-muted`, `ds-fg-subtle` | Подписи будущего и заблокированного шагов, номер будущего шага и пояснения |
| `ds-border-width-strong` | Толщина границы кружка |
| `ds-gap-sm` | Расстояния между кружком, подписью и соединителем |
| `ds-icon-xs` | Размер галочки |
| `ds-type-eyebrow`, `ds-type-ui`, `ds-type-caption` | Типографика номера, подписи и пояснения |
| `ds-surface-hover`, `ds-surface-active` | Подложка доступного шага при наведении / клавиатурном фокусе и нажатии |
| `ds-radius-md` | Скругление подложки шага |
| `ds-focus-width`, `ds-focus-color`, `ds-focus-offset` | Кольцо клавиатурного фокуса и запас места вокруг него |
| `ds-transition-control` | Плавность изменения подложки |
| `ds-border-strong`, `ds-surface` | Ползунок и дорожка горизонтальной полосы прокрутки |
