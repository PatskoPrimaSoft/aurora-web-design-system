## Правила применения

- Передавайте `DsToast` со стабильными уникальными `key`, от старого к новому. Список и удаление по `onClose` хранит приложение; новое уведомление получает новый ключ.
- Одновременно видны до трёх сообщений (`maxVisible`). Уходящий тост занимает место до конца анимации; следующее ожидает, не объявляется скринридером и не запускает таймер до показа. Очередь поступает в порядке `children`.
- По умолчанию старые сообщения сверху. `order="newest-first"` разворачивает только видимую группу: новые ожидающие сообщения не вытесняют уже показанные. Не переставляйте `children` для задания визуального порядка.
- Название группы задаёт `label`, по умолчанию «Уведомления». Оно доступно как скрытый заголовок h2. Объявления задаются на каждом `DsToast`; внешний `aria-live` не нужен.
- По умолчанию стек размещается у родителя. `portal` переносит его в `document.body`, чтобы избежать обрезания и влияния `transform` предков; `container` задаёт другой DOM-контейнер и имеет приоритет. Контейнер должен наследовать нужные токены темы.
- В модальном сценарии стек или его portal-контейнер должен находиться внутри области фокуса `DsDialog`. Не отправляйте уведомление диалога в `document.body`: его действия окажутся вне клавиатурной навигации диалога.
- Когда удаляется тост с фокусом, фокус переходит к следующему, затем к предыдущему. После последнего — к `returnFocusRef`, а без него к элементу, активному при первом показе. Если фокус вне стека, удаление сообщений его не перемещает.
- В очереди используйте закрываемые сообщения. Не смешивайте их с незакрываемыми: постоянное сообщение может занять место и заблокировать очередь. Длительную проблему показывайте через `DsBanner` или сообщение рядом с затронутой областью. Критические сообщения не должны закрываться по таймеру.
- Ограничивайте частоту и общий объём уведомлений в приложении; повторяющиеся события лучше объединять. `maxVisible` ограничивает показ, а не размер входного списка. Пишите кратко, особенно для маленьких экранов.
- Стек учитывает безопасные отступы экрана. Анимации входа, ухода и освобождения места отключаются при reduced motion; уходящий тост исключается из фокуса, его таймер останавливается.

## Пример кода

```jsx
import { useRef, useState } from 'react';
import { DsButton, DsToast, DsToastStack } from '@primasoftllc/design-system';

function Notifications() {
  const [items, setItems] = useState([]);
  const serial = useRef(0);
  const trigger = useRef(null);

  return <>
    <DsButton onClick={event => {
      trigger.current = event.currentTarget;
      const item = { id: ++serial.current, text: 'Настройки сохранены.' };
      setItems(list => [...list, item]);
    }}>Показать уведомление</DsButton>
    <DsToastStack portal position="bottom-right" order="newest-first"
      maxVisible={3} label="Результаты сохранения" returnFocusRef={trigger}>
      {items.map(item => <DsToast key={item.id} tone="success"
        onClose={() => setItems(list => list.filter(x => x.id !== item.id))}>
        {item.text}
      </DsToast>)}
    </DsToastStack>
  </>;
}
```
