## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-icon` | Размер иконки по умолчанию и внутри контролов |
| `ds-icon-xs` | Размер рядом с мелким текстом при явном `size` |
| `ds-icon-sm` | Размер в плотных строках при явном `size` |
| `ds-icon-lg` | Размер отдельной иконки при явном `size` |

Цвет иконки наследуется от родителя; собственного цветового токена у DsIcon нет.
