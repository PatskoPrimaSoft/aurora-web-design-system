## Правила применения

- Один смысл — один символ во всём продукте. Для основных действий используйте общий словарь ниже; новый символ сначала проверьте в контексте задачи.
- Добавляйте видимую подпись к редкому или неоднозначному действию. Подсказка при наведении помогает уточнить смысл, но не заменяет доступное имя кнопки.
- Не используйте одинаковую иконку для разных действий рядом. Декоративные иконки не должны конкурировать с основным действием.

### Выбор символа

Начальный словарь для интерфейсов Aurora. Иконка дополняет название действия; её техническое имя используется только в коде.

| Действие | Имя иконки | Подпись |
| --- | --- | --- |
| Поиск | `search` | Найти объект |
| Добавление | `add` | Добавить объект |
| Редактирование | `edit` | Изменить название |
| Удаление | `delete` | Удалить объект |
| Закрытие | `close` | Закрыть окно |
| Настройки | `settings` | Настройки |

Закрытие окна и удаление данных — разные действия. Не обозначайте удаление крестиком. Символ `navigation` передаёт направление объекта, а не универсальную команду перехода.

### Размер, цвет и доступность

- Используйте имена из словаря иконографики продукта. DsIcon рисует глиф Material Symbols Outlined из локального шрифта.
- Предпочитайте параметр `size` для задания размера: он согласованно задаёт размер глифа и его области. Именованные значения автоматически учитывают плотность интерфейса. Не переопределяйте только `fontSize` через CSS или `style`, оставляя прежние ширину и высоту.
- Используйте `size="md"` внутри контрола (по умолчанию), `lg` для отдельной иконки, `sm` в плотных строках. `xs` оставляйте для шевронов и вспомогательных символов; подробные смысловые иконки должны оставаться читаемыми. Размеры связаны с токенами и учитывают плотность; числовые размеры и CSS-длины также поддерживаются.
- Цвет наследуется от родителя. Для брендовой заливки используйте `ds-on-brand`; на обычной поверхности — `ds-*-fg`, на инверсной — `ds-*-fg-on-inverse`. Не передавайте состояние только цветом: используйте понятный символ и текст.
- По умолчанию иконка скрыта от скринридера. Если рядом есть текст или иконка находится в кнопке с доступным именем, отдельный `label` не нужен. Задавайте `label`, когда иконка сама передаёт факт: она получает `role="img"` и доступное имя.
- Поворот должен передавать смысл, например курс объекта. `rotate` задаётся в градусах по часовой стрелке.
- Отступы и область нажатия задаёт родитель, а не иконка. Для нажатия используйте DsIconButton с доступным именем: сама иконка не является интерактивным контролом. Область нажатия должна быть не меньше 24×24 px. Не создавайте собственный span со шрифтовым классом в обход DsIcon.

## Пример кода

```jsx
import { useState } from 'react';
import { DsButton, DsIcon } from '@primasoftllc/design-system';

export function HeadingExample() {
  const [course, setCourse] = useState(45);

  return (
    <div style={{ display: 'flex', alignItems: 'center', gap: 12, flexWrap: 'wrap' }}>
      <DsIcon name="navigation" rotate={course} />
      <span>Курс: {course}°</span>
      <DsButton tone="secondary" onClick={() => setCourse((course + 45) % 360)}>
        Повернуть на 45°
      </DsButton>
    </div>
  );
}
```
