## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-surface`, `ds-surface-raised` | Фон встроенной и плавающей панели соответственно |
| `ds-border`, `ds-border-strong` | Обычная рамка встроенной панели и усиленная рамка плавающей; `ds-border` также разделяет действия |
| `ds-shadow-lg` | Тень плавающей панели |
| `ds-radius-container` | Скругление панели |
| `ds-fg`, `ds-type-ui`, `ds-weight-medium` | Подпись выбора с типографикой кнопок и выделенное число |
| `ds-pad-tight`, `ds-pad-sm` | Внутренние отступы панели по вертикали и горизонтали |
| `ds-gap-2xs`, `ds-gap-sm` | Отступы разделителя и расстояния между элементами |
| `ds-fg-muted`, `ds-surface-hover`, `ds-surface-active` | Текст, фон наведения и нажатия встроенных кнопок `DsButton` с тоном `ghost` |
| `ds-control-h-sm`, `ds-radius-control`, `ds-type-ui` | Высота, скругление и текст встроенных кнопок |
| `ds-focus-width`, `ds-focus-color`, `ds-focus-offset` | Кольцо клавиатурного фокуса кнопок |
| `ds-transition-control` | Плавность изменения оформления кнопок |
