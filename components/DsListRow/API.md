## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-row-h-lg` | Минимальная высота строки с учётом плотности интерфейса |
| `ds-pad-sm`, `ds-pad-tight`, `ds-gap-sm` | Боковые и вертикальные отступы, интервалы между областями строки |
| `ds-radius-md`, `ds-radius-sm` | Скругление подложки строки и основной области |
| `ds-surface-selected` | Подложка открытой (active) или выбранной чекбоксом (selected) строки |
| `ds-surface-hover`, `ds-surface-active` | Подложка доступной строки при наведении, фокусе внутри и нажатии |
| `ds-brand-text`, `ds-overlay-hover`, `ds-overlay-press` | Оверлей наведения и нажатия поверх выбранной подложки |
| `ds-brand` | Полоса слева у активной строки |
| `ds-fg`, `ds-fg-subtle` | Основной текст и второстепенные подписи |
| `ds-type-body-strong`, `ds-type-caption`, `ds-type-mono`, `ds-font-mono` | Название, подписи, значение справа и моноширинный подзаголовок |
| `ds-neutral-bg`, `ds-fg-muted`, `ds-icon-sm` | Подложка, цвет и размер обычной иконки, когда не задан state |
| `ds-transition-control` | Плавность изменения подложки |
| `ds-surface-inverse`, `ds-fg-on-inverse`, `ds-shadow-sm` | Фон, текст и тень подсказки |
| `ds-focus-width`, `ds-focus-color`, `ds-focus-offset` | Кольцо клавиатурного фокуса основной кнопки |

Статусный символ использует токены DsStateIcon, дополнительные действия — DsIconButton, метка — DsLozenge. Их оформление описано на соответствующих страницах.
