## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-type-caption`, `ds-fg-muted` | Подпись выбора размера, диапазон записей и доступные стрелки |
| `ds-font-mono` | Моноширинные цифры диапазона |
| `ds-gap-sm-plus`, `ds-gap-sm` | Интервалы между частями пагинации и подписью селекта |
| `ds-brand-subtle`, `ds-brand-text` | Подложка и текст текущей страницы |
| `ds-overlay-hover`, `ds-overlay-press` | Обратная связь при наведении и нажатии текущей страницы |
| `ds-type-ui`, `ds-radius-control`, `ds-gap-sm` | Типографика, скругление и внутренние интервалы кнопок номеров |
| `ds-control-h-sm` | Высота селекта и размер кнопок |
| `ds-surface`, `ds-fg`, `ds-border-field` | Заливка, текст и граница селекта |
| `ds-radius-xs` | Скругление селекта |
| `ds-icon-sm`, `ds-radius-icon-button` | Размер стрелок и скругление их кнопок |
| `ds-surface-hover`, `ds-surface-active` | Фон доступной кнопки при наведении и нажатии |
| `ds-fg-disabled` | Стрелки недоступных переходов |
| `ds-focus-width`, `ds-focus-color`, `ds-focus-offset` | Общее кольцо клавиатурного фокуса |
| `ds-transition-control` | Плавность изменения оформления кнопок |
