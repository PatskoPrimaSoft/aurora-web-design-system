## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-field-h` | Минимальная высота input и select с учётом плотности |
| `ds-surface`, `ds-fg` | Заливка и значение доступного поля |
| `ds-bg` | Заливка поля только для чтения |
| `ds-surface-disabled`, `ds-fg-disabled` | Заливка и значение недоступного поля |
| `ds-border-width`, `ds-border-field`, `ds-radius-md` | Толщина, цвет границы и скругление оболочки |
| `ds-border-field-hover` | Граница при наведении |
| `ds-brand` | Граница оболочки при фокусе внутри |
| `ds-focus-width`, `ds-focus-color`, `ds-focus-offset` | Кольцо фокуса общей оболочки |
| `ds-danger-solid`, `ds-danger-fg` | Рамка ошибки, отметка обязательного поля и цвет сообщения об ошибке |
| `ds-type-body` | Типографика обычного значения |
| `ds-type-mono` | Типографика значения при mono |
| `ds-type-caption`, `ds-weight-medium`, `ds-fg-muted` | Обычная подпись над полем |
| `ds-fg-subtle` | Подсказка, иконки, suffix и счётчик |
| `ds-brand-text` | Цвет подписи в рамке при фокусе |
| `ds-icon` | Размер ведущей иконки и стрелки select |
| `ds-gap-sm` | Интервал внутри оболочки между значением и дополнительными элементами |
| `ds-transition-control` | Плавность изменения оболочки и подписи в рамке |
