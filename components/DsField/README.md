## Правила применения

- По умолчанию подпись находится над полем. Не заменяйте её placeholder: подсказка внутри исчезает после ввода. `labelMode="notch"` предназначен для соседства с ещё не перенесёнными формами.
- Выберите `as="input"`, `select` или `textarea`. Тип обычного ввода задаёт `type`; варианты выбора — `options`, число строк textarea — `rows`. `as="select"` раскрывает нативный список браузера; для системного оформления списка используйте [DsSelect](../DsSelect/README.md), как в живом примере группы.
- Используйте `value` с `onChange` для управляемого поля или `defaultValue` для начального значения неуправляемого. Не передавайте оба одновременно.
- Нативные параметры `name`, `autoComplete`, `inputMode`, `maxLength`, `min` и `max` передаются соответствующему элементу. Типы событий и ref соответствуют выбранному `as`; ref указывает на input, select или textarea. Внешние `onFocus` и `onBlur` вызываются вместе с внутренними обработчиками.
- `error` заменяет `hint`, выделяет рамку и задаёт `aria-invalid`. Пояснение, единицы и счётчик связаны с полем через `aria-describedby`; внешний список ID дополняет их. Проверку значения и момент показа ошибки определяет форма.
- `required` включает нативное обязательное заполнение и добавляет отметку к обычной подписи. Для собственного сценария проверки форма может использовать `noValidate`.
- Единицы измерения передавайте через `suffix`. Для select справа показывается стрелка, suffix не выводится.
- `mono` подходит для идентификаторов и числовых значений, которые нужно сравнивать посимвольно.
- Высота поля зависит от токенов плотности; textarea по умолчанию допускает ручное изменение высоты. `autoResize` автоматически увеличивает и уменьшает её по содержимому; `rows` задаёт исходную высоту, `maxHeight` ограничивает рост. Если предел достигнут, появляется прокрутка. Внешние интервалы между полями задаёт родитель.
- `showCount` показывает количество символов textarea; `maxLength` задаёт нативный лимит. Счётчик связан с полем, но не объявляет каждое нажатие. Текст берётся из `DsStringsProvider.field.count`.
- `readOnly` у input и textarea сохраняет возможность фокуса, выделения и копирования; select не поддерживает нативное чтение без редактирования. `disabled` блокирует поле и не реагирует на наведение. Причину недоступности показывайте в `hint`.
- Доступное поле входит в последовательность Tab. Select и textarea сохраняют нативное клавиатурное поведение; `disabled` исключает поле из последовательности Tab.
- Проверяйте заполненное поле после выхода из него и всю форму при отправке. После обнаружения ошибки обновляйте результат при исправлении; при неудачной отправке переводите фокус на первое ошибочное поле через ref. Не объявляйте одну ошибку одновременно несколькими live regions.
- Системная оболочка рисует фокус вокруг всего поля. Для связанного label и ссылок из других элементов можно задать стабильный `id`.

## Пример кода

```jsx
import { useRef, useState } from 'react';
import { DsField, DsButton } from '@primasoftllc/design-system';

function ObjectNameForm() {
  const inputRef = useRef(null);
  const [name, setName] = useState('MAZ 5440');
  const [error, setError] = useState('');
  const [saved, setSaved] = useState('');

  function submit(event) {
    event.preventDefault();
    if (!name.trim()) {
      setError('Введите название объекта.');
      setSaved('');
      inputRef.current.focus();
      return;
    }
    setError('');
    setSaved(`Сохранено: ${name.trim()}`);
  }

  return (
    <form onSubmit={submit} noValidate>
      <DsField
        ref={inputRef}
        id="object-name"
        label="Название объекта"
        value={name}
        onChange={event => {
          setName(event.target.value);
          setError('');
          setSaved('');
        }}
        required
        error={error}
      />
      <DsButton type="submit">Сохранить</DsButton>
      <p role="status">{error || saved}</p>
    </form>
  );
}
```
