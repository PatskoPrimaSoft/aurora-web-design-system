## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-header-h` | Высота шапки в выбранной плотности |
| `ds-header-bg`, `ds-header-fg`, `ds-header-fg-muted` | Фон, название продукта и дополнительный контекст |
| `ds-header-border` | Разделитель шапки и содержимого |
| `ds-header-plate` | Подложка знака бренда |
| `ds-header-env-bg`, `ds-header-env-fg` | Метка окружения |
| `ds-shadow-sm` | Тень шапки после прокрутки содержимого |
