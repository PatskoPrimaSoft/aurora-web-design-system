## Правила применения

Шапка нейтральная: бренд выделяет плашку логотипа и активный раздел.
Цветная заливка всей полосы не используется по умолчанию.

- Высота из плотности: 56px cozy, 48px compact. Заголовок продукта — интерфейсным начертанием.
- Все цвета — `--ds-header-*`; тенант с цветной полосой переопределяет эти алиасы в своём блоке темы.
- Знак и заголовок тенанта меняются в рантайме — никогда не считайте локап блоком фиксированной ширины.
- `scrolled` поднимает тень, когда под шапку уехал контент; в покое шапка отделяется границей.

### Логотип и цвета

Знак лежит на плашке 34px, изображение занимает 26px. Штатный знак белый
на прозрачном фоне, поэтому ему нужна брендовая подложка `ds-header-plate`.
Если у арендатора есть подходящий для поверхности вариант знака, плашку можно
сделать прозрачной через этот токен.

Шапка, навигация, действия и счётчики используют роли `ds-header-*`:
фон, основной и второстепенный текст, границу, hover, плашку логотипа,
индикатор выбранного раздела, окружение и уведомления.
Тема и оформление задаются атрибутами `data-ds-theme` и `data-ds-appearance`
на предке. Для DEFAULT/RED2, light/dark и cozy/compact используйте
переключатели каталога или «Сравнить 4 режима»; пример наследует выбранный режим.

### Навигация

`DsTabs tone="onHeader"` по умолчанию располагает иконку над подписью,
а счётчик — над иконкой. Это экономит ширину для длинных переводов.
Для двух-трёх коротких разделов доступен `stack={false}`: иконка и подпись
стоят в одну строку. Оба варианта показаны в превью.

На узком экране оставляйте место для навигации: скрывайте дополнительную метку
окружения и необязательные действия, сокращайте название продукта. Длинная
навигация прокручивается внутри шапки.

Активный раздел выделяют брендовые чернила и нижний индикатор 3px.
Счётчик уведомлений использует акцентную заливку без обводки и ореола.
`section` нужен для дополнительного контекста; повторять им название
уже выделенного раздела не нужно.

### Действия и пользователь

Действия справа передаются в `actions` или одноимённый слот.
Для иконок используйте `DsIconButton tone="onHeader"` с понятной подписью.
Для меню пользователя передавайте `DsUserMenu` в `actions`.

Связанные компоненты: [вкладки](../DsTabs/README.md),
[меню пользователя](../DsUserMenu/README.md).

## Пример кода

```jsx
import { useState } from 'react';
import { DsAppHeader, DsTabs, DsUserMenu } from '@primasoftllc/design-system';

export function ApplicationHeader() {
  const [active, setActive] = useState('objects');
  const [message, setMessage] = useState('');
  return (
    <div>
      <DsAppHeader
        product="Aurora"
        actions={
          <DsUserMenu
            name="Анна Иванова"
            items={[{ id: 'profile', label: 'Профиль' }, { id: 'settings', label: 'Настройки' }]}
            onSelect={item => setMessage('Выбрано: ' + item.label)}
          />
        }
      >
        <DsTabs
          tone="onHeader"
          active={active}
          onChange={setActive}
          items={[
            { id: 'objects', label: 'Объекты', icon: 'directions_car' },
            { id: 'reports', label: 'Отчёты', icon: 'assessment' },
          ]}
        />
      </DsAppHeader>
      <p role="status">{message || 'Открыт раздел: ' + active}</p>
    </div>
  );
}
```
