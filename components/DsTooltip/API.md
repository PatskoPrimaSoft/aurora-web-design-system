## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-surface-inverse` | Контрастная поверхность подсказки |
| `ds-fg-on-inverse` | Текст на контрастной поверхности |
| `ds-type-caption` | Компактная типографика пояснения |
| `ds-pad-tight`, `ds-pad-sm` | Вертикальные и горизонтальные отступы |
| `ds-radius-sm` | Скругление подсказки |
| `ds-shadow-sm` | Отделение подсказки от содержимого |
