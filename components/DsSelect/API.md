## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-field-h` | Минимальная высота закрытого поля |
| `ds-surface`, `ds-fg`, `ds-fg-muted` | Поверхность, выбранное значение и placeholder |
| `ds-surface-disabled`, `ds-fg-disabled` | Недоступное поле и текст недоступных вариантов |
| `ds-border-width`, `ds-border-field`, `ds-radius-field` | Рамка и скругление поля |
| `ds-border-field-hover`, `ds-brand` | Рамка при наведении и фокусе |
| `ds-focus-width`, `ds-focus-color`, `ds-focus-offset` | Фокус поля и выделение активного варианта |
| `ds-surface-raised`, `ds-border`, `ds-radius-md`, `ds-shadow-md` | Поверхность, рамка, скругление и тень списка |
| `ds-surface-selected`, `ds-surface-hover` | Выбранный и активный варианты |
| `ds-control-h` | Минимальная высота варианта в списке |
| `ds-gap-xs`, `ds-gap-sm`, `ds-pad-tight`, `ds-pad-sm` | Отступы списка и элементов внутри него |
| `ds-radius-xs` | Скругление отдельного варианта |
| `ds-type-body`, `ds-type-caption`, `ds-weight-medium` | Типографика значений, подписи и пояснения |
| `ds-fg-subtle` | Цвет подсказки |
| `ds-danger-solid`, `ds-danger-fg` | Отметка обязательности, рамка и сообщение об ошибке |
| `ds-icon`, `ds-icon-sm` | Стрелка раскрытия и отметка выбранного варианта |
| `ds-transition-control` | Плавность изменения оформления поля |
