## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-{tone}-bg`, `ds-{tone}-fg`, `ds-{tone}-line` | Заливка, текст и граница метки с тинтом; `{tone}` соответствует выбранному тону |
| `ds-{tone}-solid` | Сплошная заливка; цвет точки в метке с тинтом |
| `ds-on-solid` | Текст, иконка и точка на сплошной заливке |
| `ds-radius-badge` | Скругление метки; общий токен пилюли, также используемый счётчиками |
| `ds-type-caption`, `ds-weight-medium` | Типографика текста |
| `ds-icon-xs` | Размер иконки |
