## Правила применения

- Таблица отображает переданные строки. Сортировку, пагинацию и выбранные ID хранит экран; компонент сам не переставляет и не фильтрует данные.
- Помечайте `sortable` только доступные для сортировки столбцы. `onSort` получает ключ столбца и следующее направление; повторное нажатие меняет возрастание на убывание. При серверной пагинации запрашивайте заново всю выборку и возвращайтесь на первую страницу.
- `selectedIds` — выбор чекбоксами, `activeId` — объект под просмотром с полосой слева. Клик по строке вызывает `onRowClick`; чекбокс и другие контролы внутри строки выполняют только своё действие.
- Чекбокс заголовка выбирает видимые строки через `onToggleVisible`. Сохраняйте выбранные ID с других страниц. Выбор всей выборки задаётся отдельно через `allSelected`, `totalCount`, `onSelectAll` и `onClearSelection`; исключения при снятии отдельных строк обрабатывает экран.
- Для открытия с клавиатуры используйте кнопку в опорном столбце: по умолчанию первом, либо отмеченном `rowAction`. Заголовки сортировки и чекбоксы доступны через Tab; кнопки работают по Enter и Space, чекбоксы — по Space. Задайте `rowLabel`, если значение опорной ячейки не даёт понятного имени чекбоксу.
- Задайте таблице понятное имя через видимый `caption` или `ariaLabel`. Если таблиц несколько, имена должны различаться.
- `fixedLayout` сохраняет ширины столбцов независимо от содержимого. Задайте `columns[].width` для важных столбцов; остальные разделят свободное место. Сокращённый текст раскрывается по наведению и фокусу, Escape закрывает подсказку. `wrap` включает перенос вместо сокращения.
- Числовые значения выравнивайте вправо; `mono` используйте для номеров, времени и координат. Через `render` можно добавить форматирование, статус или действие; `wrap` разрешает перенос длинного текста.
- В обычной странице оставляйте таблице высоту по содержимому. В ограниченной панели прокрутка и `stickyHeader` работают внутри её области; на узком экране допустима горизонтальная прокрутка таблицы.
- `empty` объясняет отсутствие результата и предлагает следующий шаг; ошибка запроса и отсутствие данных требуют разных сообщений. `footer` подходит для `DsPagination` или сводки выбора. Оба блока также принимают дочерние элементы с `slot="empty"` и `slot="footer"`.

## Пример кода

```jsx
import { useState } from 'react';
import { DsTable } from '@primasoftllc/design-system';

const rows = [
  { id: 1, name: 'MAZ 5440', group: 'Грузовики' },
  { id: 2, name: 'GAZ Next', group: 'Фургоны' },
];

const columns = [
  { key: 'name', label: 'Объект', strong: true, sortable: true },
  { key: 'group', label: 'Группа' },
];

export function ObjectsTable() {
  const [sort, setSort] = useState({ key: 'name', dir: 'asc' });
  const sorted = [...rows].sort((a, b) =>
    a[sort.key].localeCompare(b[sort.key], 'ru') *
    (sort.dir === 'asc' ? 1 : -1)
  );

  return (
    <DsTable
      ariaLabel="Объекты с сортировкой"
      columns={columns}
      rows={sorted}
      sortKey={sort.key}
      sortDir={sort.dir}
      onSort={(key, dir) => setSort({ key, dir })}
    />
  );
}
```
