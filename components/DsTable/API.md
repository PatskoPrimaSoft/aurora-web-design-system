## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-surface` | Основная поверхность таблицы |
| `ds-bg` | Фон заголовка и подвала |
| `ds-border` | Внешняя рамка и границы заголовка и подвала |
| `ds-divider` | Разделители строк |
| `ds-surface-hover` | Фон обычной строки и кнопки сортировки при наведении |
| `ds-surface-selected` | Фон выбранной строки и объекта под просмотром |
| `ds-brand` | Полоса слева у объекта под просмотром |
| `ds-brand-subtle` | Фон предложения выбрать всю выборку |
| `ds-brand-text` | Активная сортировка и действия с выборкой |
| `ds-fg` | Основной текст |
| `ds-fg-muted` | Заголовки и вторичные ячейки с `muted` |
| `ds-fg-subtle` | Неактивные значки сортировки и стандартное пустое состояние |
| `ds-type-body`, `ds-type-ui`, `ds-type-mono` | Текст ячеек, действия с выборкой и моноширинные значения |
| `ds-type-body-strong` | Заголовки столбцов и подпись таблицы |
| `ds-weight-medium` | Выделение опорных ячеек с `strong` |
| `ds-row-h` | Минимальная высота строки, зависит от плотности |
| `ds-cell-pad-x`, `ds-cell-pad-y` | Внутренние отступы ячеек |
| `ds-pad-tight`, `ds-pad-sm` | Отступы предложения выбрать всю выборку и подвала |
| `ds-radius-container` | Скругление внешней рамки |
| `ds-overlay-hover` | Оверлей цвета `ds-brand-text` при наведении на выбранную или просматриваемую строку |
| `ds-surface-inverse`, `ds-fg-on-inverse` | Фон и текст подсказки с полным значением |
| `ds-type-caption`, `ds-radius-sm`, `ds-shadow-sm` | Типографика, скругление и тень подсказки |
| `ds-transition-control` | Переход оформления кнопки сортировки |
| `ds-icon-xs` | Размер значков сортировки |
| `ds-dur-fast`, `ds-ease` | Плавность изменения фона строки и цвета сортировки |
| `ds-focus-width`, `ds-focus-color`, `ds-focus-offset` | Общее кольцо клавиатурного фокуса кнопок |

Чекбоксы используют токены DsCheckbox; содержимое, переданное через `render`, `empty` и `footer`, — токены соответствующих компонентов.
