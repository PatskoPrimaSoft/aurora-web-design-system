## Правила применения

- Используйте для состояния объекта мониторинга. Значок и подпись помогают различать состояния без опоры только на цвет.
- Передавайте `course` в градусах: 0° — север, 90° — восток. Поворот применяется только при `state="moving"`.
- Размер по умолчанию — 28 px; для плотной ячейки используйте 20 px. Размеры диска / глифа: 20 / 16, 28 / 20 и 36 / 24 px.
- `bare` убирает диск, например для размещения поверх карты. Проверяйте читаемость значка на фактической подложке.
- Рядом с текстом того же состояния задавайте `decorative`, чтобы скринридер не повторял подпись. В этом режиме подсказка также скрыта. Если значок сообщает дополнительную информацию (например, курс), оставьте доступное имя с этой информацией.
- В обычном режиме компонент имеет `role="img"`, доступное имя и нативную подсказку. Подпись берётся из словаря локализации; `label` позволяет уточнить её для конкретного объекта.
- Это индикатор, а не кнопка: он не получает клавиатурный фокус. Действие оформляйте отдельным интерактивным компонентом.

## Пример кода

```jsx
import { DsStateIcon } from '@primasoftllc/design-system';

export function ObjectState() {
  return (
    <div style={{ display: 'flex', alignItems: 'center', gap: 8 }}>
      <DsStateIcon
        state="moving"
        course={45}
        decorative
      />
      <span>Движение, курс 45°</span>
    </div>
  );
}
```
