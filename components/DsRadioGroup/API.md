## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-control-h` | Область нажатия в выбранной плотности |
| `ds-border-control` | Граница невыбранного варианта |
| `ds-brand / ds-on-brand` | Выбранное состояние |
| `ds-focus-color / ds-focus-width / ds-focus-offset` | Клавиатурный фокус |
| `ds-type-body / ds-type-caption` | Подписи и пояснения |
| `ds-danger-fg` | Сообщение ошибки |
