## Правила применения

- Используйте группу, когда нужно выбрать один вариант и полезно видеть все альтернативы. Для длинного списка используйте DsSelect; для независимых опций — DsCheckbox.
- Передайте общую подпись label и варианты с уникальными непустыми value. Подпись каждого варианта должна объяснять результат выбора. Причину недоступности указывайте в description.
- value вместе с onChange задаёт управляемый выбор. defaultValue задаёт начальное значение неуправляемой группы; нативный reset восстанавливает его. Управляемое значение при сбросе обновляет приложение.
- name задаёт ключ в FormData. Независимые группы должны иметь разные имена; без name компонент создаёт уникальное. form связывает поля с формой вне контейнера.
- required включает нативную проверку и сообщение после попытки отправки. Серверную ошибку передайте в error; она заменяет hint. Само приложение отвечает за проверку серверных условий.
- Tab входит в группу, стрелки выбирают соседний доступный вариант, Space выбирает сфокусированный. Внешние отступы задаёт родитель.
- Старый DsCheckbox radio остаётся доступным для совместимости; новые группы оформляйте через DsRadioGroup.

## Пример кода

```jsx
import * as React from 'react';
import * as S from '@primasoftllc/design-system';

export function Example(){
const [value,setValue]=React.useState('important');
return <S.DsRadioGroup label="Какие уведомления получать" value={value} onChange={setValue} options={[{value:'all',label:'Все события'},{value:'important',label:'Только важные',description:'Тревоги и потеря связи'},{value:'none',label:'Не получать'}]}/>;
}
```
