## Правила применения

- Используйте панель для небольшого действия рядом с кнопкой: уточнить параметры, изменить фильтр или просмотреть подробности. Для списка команд используйте `DsMenu`, для простой текстовой подсказки — `DsTooltip`, для обязательного подтверждения — `DsDialog`.
- `label` задаёт доступное имя панели: коротко назовите её задачу. Видимый заголовок при необходимости добавляет содержимое. Панель объявляется немодальным диалогом; остальная страница остаётся доступной.
- Передайте кнопку через `trigger`. Для своей кнопки можно использовать функцию и передать полученные свойства одному DOM-контролу. Существующий ref элемента сохраняется; компонент не требует `forwardRef` от `DsButton`.
- Enter, Space и нажатие раскрывают панель. Фокус переходит на первый доступный контрол; если контролов нет — на саму панель. Tab проходит содержимое и выходит к следующему элементу страницы, Shift+Tab с первого контрола возвращает к кнопке. Фокус не запирается.
- Escape закрывает только верхний слой и возвращает фокус к кнопке. Для собственного действия завершения используйте `children={({close}) => …}`. Клик или переход фокуса снаружи закрывает панель без переноса фокуса назад.
- Значения полей хранит приложение: закрытие панели размонтирует содержимое. Для управляемого раскрытия передавайте `open` и `onOpenChange`; внешнее закрытие возвращает фокус на кнопку.
- `placement` и `align` задают предпочтительную сторону и край привязки. Панель меняет сторону при нехватке места, ограничивается экраном и при необходимости прокручивается. Ширина задаётся в px или по содержимому через `auto`.
- Тема и плотность наследуются от места использования. В браузерах с Popover API панель остаётся над обрезающими контейнерами и внутри DOM родительского диалога. Без Popover API избегайте обрезающих контейнеров с `transform`. В каталоге границей служит iframe примера.

## Пример кода

```jsx
import { useState } from 'react';
import { DsButton, DsCheckbox, DsPopover } from '@primasoftllc/design-system';
import '@primasoftllc/design-system/styles.css';

export function Example() {
  const [active, setActive] = useState('unchecked');
  return <DsPopover label="Фильтр объектов" trigger={<DsButton tone="secondary">Фильтр</DsButton>}>
    {({close}) => <div style={{display:'flex', flexDirection:'column', gap:16}}>
      <DsCheckbox label="Только активные" state={active} onChange={setActive}/>
      <DsButton onClick={close}>Готово</DsButton>
    </div>}
  </DsPopover>;
}
```
