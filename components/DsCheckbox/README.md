Чекбокс и радио одним компонентом (флаг `radio`) для форм и списков фильтров.

**Потребитель задаёт** `label`, `checked` и `onChange`, при необходимости `description` (вторая строка), `indeterminate`, `radio` с `name` / `value`, `disabled`.

- Любое выбранное состояние — `--ds-brand`. Акцент — только для внимания; в старом продукте выбор был акцентным, а дата в календаре — primary, это исправлено.
- `indeterminate` рисует прочерк — для «выбрать всё» в заголовке таблицы. Внутри это `DsCheck` в состоянии `indeterminate`.
- Нажатие на частично выбранный чекбокс выбирает всё: `onChange` получает `event.target.checked === true`. Потребитель обновляет `checked` и снимает `indeterminate`.

**Не делайте:** отключение через прозрачность — отключённое передаётся цветом.
