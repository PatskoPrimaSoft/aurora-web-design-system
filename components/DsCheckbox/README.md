Чекбокс выбирает отдельные элементы или всю группу. Радио выбирает один вариант из группы.

Символ — 18 × 18 px. Область нажатия следует плотности; в таблице — 24 × 24 px.

Задавайте `state` и обновляйте его через `onChange(nextState)`. Нажатие на частично выбранный чекбокс выбирает всё. Для радио используйте `unchecked` или `checked` и общий `name` внутри группы.

`label` — видимая подпись, `description` — пояснение под ней. Без подписи задайте `ariaLabel`. Space переключает чекбокс, стрелки меняют выбор в группе радио. Enter выбор не переключает.

| Токен | За что отвечает |
| --- | --- |
| `ds-surface` | Заливка доступного невыбранного чекбокса и радио |
| `ds-brand` | Заливка и граница доступного выбранного контрола |
| `ds-on-brand` | Галочка, прочерк и точка на брендовой заливке |
| `ds-border-control` | Граница доступного невыбранного контрола |
| `ds-border-control-hover` | Его граница при наведении |
| `ds-overlay-hover` | Оверлей цвета `ds-on-brand` на выбранном контроле при наведении |
| `ds-surface-hover` | Подложка области нажатия при наведении на контрол без подписи |
| `ds-surface-disabled` | Нейтральная заливка недоступного контрола |
| `ds-border-control-disabled` | Видимая граница недоступного контрола |
| `ds-fg-control-disabled` | Галочка, прочерк и точка недоступного контрола |
| `ds-border-width-control` | Толщина границы — 2 px |
| `ds-radius-xs` | Скругление чекбокса; у радио всегда круг |
| `ds-control-h` | Область нажатия по умолчанию |
| `ds-focus-width`, `ds-focus-color`, `ds-focus-offset` | Кольцо клавиатурного фокуса |
| `ds-transition-control` | Плавность изменения оформления |
