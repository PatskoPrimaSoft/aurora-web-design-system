## Правила применения

Показывайте панель рядом с таблицей, когда выбрана хотя бы одна строка. Выбор хранит родитель: обработчики панели только запрашивают выбрать весь результат или очистить выбор. `total` должен соответствовать текущему отфильтрованному результату, а не числу строк на странице.

Оставляйте два–четыре действия, применимых ко всем выбранным строкам. Остальные убирайте в меню. Разрушающее действие выделяйте `tone="danger"` и подтверждайте в `DsDialog`.

Связанные действия оформляйте одинаково, обычно `tone="secondary"`. Выделяйте основное действие только при явном приоритете. Счётчик сообщает объём выбора; он не является кнопкой или статусной меткой.

При полном выборе кнопка «Выбрать все» скрывается. «Снять выбор» всегда одна: вызывает `onClear`, а при его отсутствии — `onSelectAll(false)`.

Внутри уже отделённой области используйте `floating={false}`: обычную поверхность и границу без тени. Плавающий вид использует приподнятую поверхность с тенью; размещение поверх таблицы задаёт родитель. На узком экране разрешайте перенос через `style`, а набор действий адаптируйте к доступной ширине.

Кнопки доступны через Tab и активируются Enter или Space. При скрытии панели после сброса выбора возвращайте фокус в управляющий элемент таблицы.

## Пример кода

```jsx
import { useState } from 'react';
import { DsBulkBar, DsButton } from '@primasoftllc/design-system';

export function Example() {
  const [count, setCount] = useState(12);
  const [message, setMessage] = useState('');

  return (
    <>
      <DsButton onClick={() => setCount(12)}>Выбрать 12 строк</DsButton>
      <DsBulkBar
        count={count}
        total={148}
        noun="объектов"
        style={{ flexWrap: 'wrap' }}
        onSelectAll={(all) => setCount(all ? 148 : 0)}
        onClear={() => setCount(0)}
        actions={
          <DsButton size="sm" tone="secondary" icon="download"
            onClick={() => setMessage('Пример: экспорт ' + count + ' объектов запрошен.')}>
            Экспорт
          </DsButton>
        }
      />
      <p role="status">{message}</p>
    </>
  );
}
```
