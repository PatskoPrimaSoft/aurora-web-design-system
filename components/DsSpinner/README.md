## Правила применения

- Используйте для операции с неизвестным прогрессом. Если форма будущего содержимого известна, выбирайте `DsSkeleton`; внутри кнопки — её параметр `loading`.
- Размещайте индикатор рядом с загружаемым содержимым. Размеры 16–20 px подходят для строки, 32 px — для области, 48 px — для страницы.
- `tone="inverse"` наследует `currentColor`: задайте родителю цвет текста, контрастный его фону.
- Индикатор имеет `role="status"`. В `label` называйте операцию, например «Загрузка отчёта». Не добавляйте второе объявление той же загрузки.
- Области данных задайте `aria-busy`. После завершения уберите индикатор и покажите данные или ошибку; сохраняйте клавиатурный фокус на текущем элементе.
- Спиннер не принимает фокус и не блокирует взаимодействие сам. Защиту от повторного запуска операции задаёт потребитель.

- После явного нажатия показывайте индикатор без задержки, чтобы подтвердить действие. Для фоновых коротких операций избегайте мелькания: при необходимости задавайте `delay`, например 500 ms. До появления кольца место под него сохраняется; при завершении операции компонент нужно размонтировать.
- Плавное появление отключается при `prefers-reduced-motion`, вращение сохраняется: неподвижное кольцо может восприниматься как остановившаяся операция.
- При обновлении сохраняйте существующие данные и показывайте один индикатор внутри обновляемой области. Если статус уже объявляется отдельным `role="status"`, оберните спиннер в `aria-hidden="true"`.

## Пример кода

```jsx
import { DsSpinner } from '@primasoftllc/design-system';
import '@primasoftllc/design-system/styles.css';

export function Report({ loading, children }) {
  return (
    <div>
      {loading && <DsSpinner size={32} delay={500} label="Загрузка отчёта" />}
      <div aria-busy={loading}>{children}</div>
    </div>
  );
}
```
