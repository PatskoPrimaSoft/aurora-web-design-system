## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-surface`, `ds-border-field`, `ds-fg` | Обычная кнопка открытия и невыбранное направление сортировки |
| `ds-brand-subtle`, `ds-brand-border`, `ds-brand-text` | Кнопка с применённым значением и выбранное направление сортировки |
| `ds-surface-raised`, `ds-border` | Подложка и граница поповера |
| `ds-surface-selected`, `ds-surface-hover` | Выбранная строка списка и наведение; при наведении выбранная заливка сохраняется |
| `ds-pad-sm`, `ds-gap-xs`, `ds-gap-md` | Отступы строк, небольшой интервал после заголовка группы и увеличенный перед следующей группой |
| `ds-weight-medium`, `ds-type-caption` | Названия групп и счётчики вариантов |
| `ds-brand`, `ds-on-brand` | Заливка и текст кнопки «Применить» |
| `ds-fg-muted` | Кнопка «Очистить» и невыбранное направление |
| `ds-fg-subtle` | Заголовок поповера, пояснения и недоступные варианты |
| `ds-divider` | Разделители перед действиями и направлениями сортировки |
| `ds-control-h`, `ds-control-h-sm` | Высота кнопки открытия и кнопок применения и направлений |
| `ds-gap-sm`, `ds-gap-sm-plus`, `ds-pad-md` | Интервалы в диапазоне и действиях, между блоками и отступы поповера |
| `ds-radius-control`, `ds-radius-md` | Скругления кнопок и поповера |
| `ds-shadow-md` | Тень поповера |
| `ds-type-ui`, `ds-type-eyebrow`, `ds-tracking-eyebrow` | Типографика кнопок и заголовка поповера |
| `ds-icon-sm`, `ds-icon` | Размеры иконок направления, кнопки открытия и очистки |
| `ds-transition-control` | Плавность оформления кнопки открытия |
| `ds-overlay-hover`, `ds-overlay-press` | Подсветка всей кнопки открытия при наведении и нажатии, включая область стрелки |
| `ds-dur-fast`, `ds-ease` | Поворот стрелки при раскрытии и закрытии |
| `ds-focus-width`, `ds-focus-color`, `ds-focus-offset` | Общий стиль клавиатурного фокуса |

Поля ввода используют токены DsField. Чекбоксы списка используют общее оформление DsCheckbox: брендовая заливка и символ, граница контрола и её толщина.
