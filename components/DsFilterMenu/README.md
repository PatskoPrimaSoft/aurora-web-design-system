Редактор фильтра в поповере, открываемом подписанной кнопкой; покрывает все восемь типов старого `CommonFilter`.

**Потребитель задаёт** `label` (он же заголовок поповера), `type`, `value`, `options` и `onApply`, при необходимости `onClear`, `trigger`, `width`.

- Типы: `string`, `number`, `number-range`, `date`, `date-range`, `checkbox-list`, `radio`, `sort-by`.
- Значение — черновик до «Применить»: наполовину введённый диапазон не перезапрашивает данные.
- Результат показывается снимаемым `DsChip` в `DsChipGroup` рядом с таблицей, а не в её заголовке.
- `sort-by` — меню сортировки для поверхностей без заголовков столбцов (панель объектов, дерево, карточки): список полей и одна пара направлений. Сортировка — не фильтр: чипом она не показывается.

**Не делайте:** фильтр в ячейке заголовка таблицы — заголовок только сортирует.
