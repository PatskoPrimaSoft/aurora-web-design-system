Позиционирует тосты на уровне страницы.

**Потребитель задаёт** тосты в `children`, при необходимости `position` — `bottom-center` или `bottom-right`.

- Один стек на страницу; тосты могут открываться поверх модального окна.

- Для анимации ухода задавайте каждому тосту стабильный уникальный key. Новое уведомление получает новый key.
- Стек ограничивает ширину окном и учитывает safe area; уходящий тост недоступен для фокуса, его таймер останавливается.
- В модальном сценарии размещайте стек внутри DsDialog, чтобы действия уведомлений оставались доступны клавишей Tab.
