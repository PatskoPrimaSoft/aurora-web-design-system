Настоящая `<button role="checkbox">` вокруг `DsCheck`: Enter, Space и кольцо `:focus-visible` приходят от платформы, а не из самописного обработчика клавиш.

**Потребитель задаёт** `state`, `onChange(next)` и `label` — на практике обязателен: это доступное имя контрола без текста.

- `state`: `unchecked` — не выбран, `checked` — выбран, `indeterminate` — частично выбран.
- Нажатие: `unchecked` / `indeterminate` → `checked`, `checked` → `unchecked`.
- Зона нажатия `hit` по умолчанию `var(--ds-control-h)`, то есть следует плотности.
- Для строки дерева и заголовка таблицы, где рядом нет подписи.

**Не делайте:** рисовать фокус из JS — фокус только CSS.
