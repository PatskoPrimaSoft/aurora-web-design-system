## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-surface`, `ds-fg`, `ds-border` | Заливка, текст и граница невыбранного чипа |
| `ds-brand-subtle`, `ds-brand-text`, `ds-brand-border` | Заливка, текст и граница выбранного фильтра |
| `ds-surface-hover` | Заливка доступного невыбранного фильтра при наведении |
| `ds-overlay-hover` | Оверлей цвета `ds-brand-text` на выбранном фильтре при наведении |
| `ds-surface-disabled`, `ds-fg-disabled` | Заливка и текст недоступного фильтра |
| `ds-neutral-bg`, `ds-neutral-fg` | Заливка и текст счётчика невыбранного чипа |
| `ds-control-h-sm`, `ds-radius-chip` | Высота и скругление чипа |
| `ds-type-ui` | Типографика подписи |
| `ds-radius-pill` | Скругление счётчика; его типографика — `ds-type-ui` |
| `ds-surface-hover`, `ds-surface-active` | Фон крестика удаления при наведении и нажатии |
| `ds-icon-sm`, `ds-icon-xs` | Размер ведущей иконки и крестика удаления |
| `ds-focus-width`, `ds-focus-color`, `ds-focus-offset` | Общее кольцо клавиатурного фокуса |
| `ds-transition-control` | Плавность изменения оформления |
