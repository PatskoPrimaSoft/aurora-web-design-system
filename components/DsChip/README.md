## Правила применения

- Для фильтра передайте `onClick` и управляйте `selected` в родителе. `count` показывает количество элементов, а не состояние выбора.
- Для удаляемого значения передайте `removable` и `onRemove`: родитель удаляет значение из списка. В этом режиме `onClick` не используется: действие принадлежит только крестику.
- Подпись должна быть короткой и понятной без иконки. Для статуса объекта используйте `DsLozenge`, для обычного действия — `DsButton`.
- `disabled` блокирует выбор и удаление. Если причина недоступности важна, объясните её рядом с контролом.
- Tab переводит фокус на фильтр или крестик; Enter и Space вызывают действие. После удаления родитель переводит фокус на соседнее значение или другой доступный контрол.
- Разрешайте перенос ряда чипов на узком экране. `maxWidth` ограничивает ширину, длинная подпись сокращается многоточием; полное текстовое имя сохраняется для скринридера. Для сложного содержимого `children` задайте `ariaLabel`.

## Пример кода

```jsx
import { useState } from 'react';
import { DsChip } from '@primasoftllc/design-system';

function OfflineFilter() {
  const [selected, setSelected] = useState(false);

  return (
    <DsChip
      selected={selected}
      count={12}
      onClick={() => setSelected(value => !value)}
    >
      Нет связи
    </DsChip>
  );
}
```
