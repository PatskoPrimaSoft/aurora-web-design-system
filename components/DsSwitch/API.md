## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-brand` | Заливка и граница включённой дорожки |
| `ds-border-control` | Заливка и граница выключенной дорожки |
| `ds-on-brand` | Бегунок и цвет оверлея при наведении на включённый переключатель |
| `ds-fg` | Подпись и цвет оверлея при наведении на выключенный переключатель |
| `ds-overlay-hover` | Интенсивность оверлея при наведении |
| `ds-surface-disabled`, `ds-border` | Заливка и граница недоступной дорожки |
| `ds-fg-disabled` | Подпись недоступного переключателя |
| `ds-fg-subtle` | Дополнительное пояснение |
| `ds-type-body`, `ds-type-caption` | Типографика подписи и пояснения |
| `ds-gap-sm` | Расстояние между дорожкой и подписью |
| `ds-radius-pill` | Скругление дорожки |
| `ds-shadow-xs` | Тень бегунка |
| `ds-dur-fast`, `ds-ease` | Плавность изменения заливки и перемещения бегунка |
| `ds-focus-width`, `ds-focus-color`, `ds-focus-offset` | Общий стиль клавиатурного фокуса на input |
