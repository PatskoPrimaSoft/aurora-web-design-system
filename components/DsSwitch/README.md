## Правила применения

Используйте для настройки, которая применяется сразу. Для выбора, подтверждаемого кнопкой «Сохранить», используйте DsCheckbox.

Подпись `label` называет настройку и остаётся одинаковой в обоих положениях. Без видимой подписи задавайте `aria-label` или `aria-labelledby`. Пояснение `description` связано с контролом через `aria-describedby`; внешнее описание дополняет его.

Компонент управляемый: передавайте `checked` и обновляйте его через `onChange(event.target.checked)`. Без `onChange` используйте только статичный образец. `disabled` запрещает изменение и исключает контрол из порядка Tab; объясняйте причину недоступности через `description`.

При сохранении передавайте `loading`: спиннер появляется сразу, повторное переключение блокируется, фокус сохраняется. Компонент не выполняет запросы и не меняет `checked` самостоятельно. При ошибке восстановите прежнее значение и покажите пояснение рядом с настройкой.

Нажатие на переключатель или подпись меняет значение. Tab переводит фокус, Space переключает настройку; Enter значение не меняет. Дорожка — 36 × 20 px, область нажатия следует `ds-control-h`. Кольцо фокуса выделяет дорожку. `ref` указывает на input; `id`, атрибуты `aria-*` и стандартные обработчики передаются ему.

## Пример кода

```jsx
import { useState } from 'react';
import { DsSwitch } from '@primasoftllc/design-system';

export function Example() {
  const [showTracks, setShowTracks] = useState(true);

  return (
    <DsSwitch
      label="Показывать треки"
      checked={showTracks}
      onChange={(event) => setShowTracks(event.target.checked)}
    />
  );
}
```
