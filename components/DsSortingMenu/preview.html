Сортировка в списке

Сортировка меняет порядок, но сохраняет состав списка. Выберите поле и направление, затем нажмите «Применить».

Краткая памятка

Название
«А → Я / Я → А» — для поиска знакомого объекта в справочнике.
Дата или время
«Сначала новые / Сначала старые» — для последних записей или истории.
Число
«Сначала больше / Сначала меньше» — для сравнения значений, например скорости.

В списке или наборе карточек используйте меню рядом с содержимым. Если есть заголовки столбцов, сортировку удобнее разместить в таблице.

Правила применения

  • Задайте начальный порядок. Выберите его по задаче: в справочнике — по названию, в журнале — сначала новые. Сброс возвращает этот порядок.
  • Показывайте применённый выбор. Название поля и направление должны быть доступны без открытия меню. В примере они указаны над списком.
  • Сохраняйте результаты. Сортировка меняет порядок, а фильтр — состав списка. Не добавляйте сортировку в чипы применённых фильтров.

Подключение и данные

Готовый DsFilterMenu type="sort-by" управляет выбором и подтверждением. Приложение перестраивает список или запрашивает данные с сервера. В примере все четыре объекта загружены целиком и сортируются в браузере.

Показать технические подробности

Поле и направление

Передавайте value={ {key, dir} }, где dir — asc или desc. У вариантов задавайте понятные подписи asc и desc. onApply получает весь выбор; onClear восстанавливает начальное значение. Не переставляйте шаги процесса и уровни дерева. Группировка объединяет объекты по признаку и не имеет направления. Если меню также содержит группировку, вариант с group: true скрывает направления; само объединение данных реализует приложение.

Порядок всего набора

Сортируйте в браузере только полностью загруженный список. При постраничной загрузке передавайте выбор серверу и возвращайтесь на первую страницу, сохраняя фильтры. Текст сравнивайте с учётом языка, числа — как числа, даты — по времени. Для одинаковых значений задайте устойчивый дополнительный порядок, например по идентификатору.

Клавиатура и собственная кнопка

Enter или Space открывает меню, стрелки перемещают фокус по полям, Space выбирает пункт. Tab переводит к направлению и действиям. Escape отменяет черновик и возвращает фокус. При передаче trigger используйте доступную кнопку с понятным именем; открытие и возврат фокуса обеспечивает компонент. Полный API — в DsFilterMenu.
