# Сортировка вне таблицы

## Подключение меню

Используйте `DsFilterMenu` с `type="sort-by"` для списка или панели
без заголовков столбцов. Храните поле и направление как `{ key, dir }`;
порядок строк после применения меняет приложение.

Для полей задайте понятные подписи направлений: «Сначала новые / Сначала
старые», «А → Я / Я → А». У группировки с `group: true` направления нет.

## Применение и сброс

Задайте порядок по умолчанию. Сброс возвращает к нему, а подтверждение
применяет весь выбор целиком. Показывайте изменённый порядок состоянием
триггера: он не уменьшает количество результатов и не является фильтром.

Проверьте открытие с клавиатуры, выбор пунктов, Escape и возврат фокуса.
API находится в [DsFilterMenu](../DsFilterMenu/README.md), а правила для
заголовков — в [разделе «Сортировка» таблицы](../DsTable/README.md).
