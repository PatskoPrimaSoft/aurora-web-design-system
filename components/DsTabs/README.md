## Правила применения

- `underline` переключает содержимое внутри страницы. `segmented` подходит для двух–трёх коротких вариантов, например периода отчёта.
- Пишите короткие подписи, обычно в 1–2 слова. Группируйте независимое содержимое одного контекста; данные, которые нужно сравнивать одновременно, оставляйте вместе. Держите число вкладок небольшим, самые важные размещайте первыми.
- Общий заголовок, пояснения и важная информация для всех вкладок располагаются над полосой. Не прячьте их внутри одной панели.
- Не вкладывайте кнопки, ссылки, меню или поля ввода в `label`: сама вкладка уже является интерактивным элементом. Действия размещайте в панели или рядом с группой.
- `onHeader` переключает разделы приложения и размещается на фоне `ds-header-bg`, обычно внутри `DsAppHeader`. По умолчанию иконка находится над подписью; `stack={false}` располагает их в строку.
- Компонент управляемый: храните выбранный `id` в `active` и обновляйте его через `onChange`. Идентификаторы элементов должны быть уникальными, а `active` — соответствовать одному из них. Если выбранный элемент удалён, первая вкладка остаётся доступна через Tab; новое значение `active` задаёт родитель.
- Для вкладок страницы передайте одинаковый уникальный `idBase` в `DsTabs` и связанные `DsTabPanel`. Панель получает `id` своей вкладки и `active`; содержимое монтируется при первом открытии и сохраняется при переключениях, включая введённые данные. `unmountOnHide` явно включает размонтирование скрытой панели и сброс её локального состояния.
- Задавайте понятное `aria-label`, особенно если на странице несколько групп вкладок. Счётчик `badge` отображается во всех вариантах: на нейтральной подложке в контенте и на акцентной подложке в шапке.
- Внутри страницы Tab переводит фокус на выбранную вкладку. Стрелки влево/вправо, Home и End перемещают фокус и сразу выбирают вкладку; Tab после вкладки переводит фокус дальше, в том числе на активную панель.
- Индикатор выбранной вкладки плавно перемещается между подписями. При reduced motion и изменении размеров он занимает новое положение сразу.
- Длинная полоса прокручивается по горизонтали внутри компонента. Выбранная или получившая фокус вкладка остаётся видимой без прокрутки всей страницы.
- В шапке каждый раздел доступен через Tab и открывается по Enter или пробелу. Выбранный раздел объявляется текущей страницей, без роли вкладки и без `DsTabPanel`.

## Пример кода

```jsx
import { useState } from 'react';
import { DsTabs, DsTabPanel } from '@primasoftllc/design-system';

const items = [
  { id: 'overview', label: 'Обзор' },
  { id: 'history', label: 'История' },
];

export function ObjectTabs() {
  const [active, setActive] = useState('overview');
  return (
    <>
      <DsTabs
        idBase="object-details"
        aria-label="Карточка объекта"
        items={items}
        active={active}
        onChange={setActive}
      />
      <DsTabPanel idBase="object-details" id="overview" active={active === 'overview'}>
        Сведения об объекте
      </DsTabPanel>
      <DsTabPanel idBase="object-details" id="history" active={active === 'history'}>
        История изменений
      </DsTabPanel>
    </>
  );
}
```
