Табы в трёх тонах: в шапке приложения, подчёркнутые в контенте и сегменты для переключения двух–трёх вариантов.

**Потребитель задаёт** `items` (`{id, label, icon?, badge?}`), `active`, `onChange`, `tone`, при необходимости `stack`.

- `onHeader` складывает иконку над подписью, счётчик садится на глиф — горизонтальное место дефицитно при 23 локалях. `stack={false}` — для двух–трёх коротких подписей.
- Выбранный таб в шапке красит глиф и подпись `--ds-header-tab-fg-active`.
- `underline` — внутри экрана, под заголовком страницы; `segmented` — выбор из двух–трёх вариантов.
