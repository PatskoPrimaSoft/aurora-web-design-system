## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-row-h` | Минимальная высота строки с учётом плотности |
| `ds-pad-sm`, `ds-pad-tight`, `ds-gap-sm` | Боковые и вертикальные отступы, интервалы между областями |
| `ds-surface-hover`, `ds-surface-active` | Подложка отдельных областей раскрытия и открытия при наведении, фокусе и нажатии |
| `ds-fg` | Название на любом уровне вложенности |
| `ds-fg-muted` | Нейтральная иконка группы |
| `ds-fg-subtle` | Шеврон, дополнительная подпись и счётчик выбранных объектов |
| `ds-type-body-strong`, `ds-type-caption` | Название, дополнительная подпись и счётчик |
| `ds-brand-subtle`, `ds-brand-text`, `ds-type-ui` | Подложка, цвет и типографика инициалов аватара |
| `ds-accent-mark`, `ds-accent-mark-on`, `ds-type-eyebrow` | Фон и текст счётчика непрочитанных |
| `ds-icon`, `ds-icon-sm` | Размер шеврона и иконки группы |
| `ds-radius-sm`, `ds-radius-circle`, `ds-radius-badge` | Скругление кнопок, аватара и счётчика непрочитанных |
| `ds-transition-control` | Плавность изменения подложки |
| `ds-control-h-sm` | Одинаковая ширина области шеврона в обоих вариантах; минимальная высота кнопки раскрытия |
| `ds-radius-md` | Скругление общей подложки открытой группы |
| `ds-surface-selected`, `ds-brand` | Подложка и полоса слева у открытой для просмотра группы |
| `ds-brand-text`, `ds-overlay-hover`, `ds-overlay-press` | Оверлей наведения, фокуса и нажатия основной области поверх active |
| `ds-surface-inverse`, `ds-fg-on-inverse`, `ds-shadow-sm` | Фон, текст и тень подсказки сокращённого названия |
| `ds-focus-width`, `ds-focus-color`, `ds-focus-offset` | Общее кольцо клавиатурного фокуса кнопок |

Оформление чекбокса определяется токенами DsCheckbox.
