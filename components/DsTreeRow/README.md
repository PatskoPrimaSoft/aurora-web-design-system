Строка дерева пользователь → группа над объектами: раскрытие, агрегированный выбор и счётчик.

**Потребитель задаёт** `title`, `level` (0 — пользователь, 1 — группа), `expanded` с `onToggle`, при необходимости `meta`, `icon` или `avatar` / `avatarSrc`, `selected` и `total`, `select` с `onSelectChange`, `selectDisabled`, `unread`, `onClick`.

- Счётчик пишется как «3 / 12», когда передан `total`.
- Выбор уровня трёхпозиционный: `indeterminate` — выбраны не все объекты внутри.
- Порядок иерархии пользователь → группа → объект — не пользовательский выбор, он не сортируется.
