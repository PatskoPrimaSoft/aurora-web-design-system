Трёхпозиционный бокс выбора со своей зоной нажатия — для дерева объектов, где у строки нет подписи рядом с боксом.

**Потребитель задаёт** `state` (`checked` · `indeterminate` · `unchecked`), `onChange(next)` и `label` — что именно выбирается («Выбрать все объекты Петрова С.»).

- `indeterminate` — частично выбранный пользователь или группа.
- Следующее состояние: `unchecked` / `indeterminate` → `checked`, `checked` → `unchecked`.

**Не делайте:** использовать его в форме — там `DsCheckbox` с подписью.
