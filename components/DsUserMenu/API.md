## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-control-h-sm` | Высота кнопки пользователя |
| `ds-header-chip-bg`, `ds-header-chip-border` | Фон и рамка кнопки пользователя |
| `ds-header-fg` | Имя пользователя в кнопке |
| `ds-surface`, `ds-border` | Фон и рамка раскрытого меню |
| `ds-fg`, `ds-fg-subtle` | Имя и дополнительная информация в меню |
