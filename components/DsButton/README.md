## Правила применения

- Выделяйте одно главное действие в области через `primary`. Для сопутствующих действий используйте `secondary` или `ghost`, для мягкого брендового акцента — `subtle`.
- `danger` обозначает разрушительное действие, например удаление; `accent` — дополнительное акцентное действие. Подпись должна объяснять результат: «Удалить объект», «Сохранить изменения».
- В группе выделяйте одно главное действие. При выравнивании справа располагайте его справа от отмены; при выравнивании слева — первым. Для удаления используйте `danger` как главное действие группы. На узком экране сохраняйте порядок при переносе.
- Высота зависит от `size` и выбранной плотности интерфейса. Используйте одинаковый размер для связанных действий; внешние отступы и расположение задаёт родитель.
- Длинная подпись переносится в пределах родителя; высота кнопки растёт вместе с текстом, поэтому подпись видна целиком без наведения. Предпочитайте короткие подписи. `fullWidth` занимает всю доступную ширину.
- Стандартные атрибуты кнопки, включая `aria-*`, `id`, `name` и `form`, передаются в DOM.
- Иконка дополняет текст. Для действия только с иконкой используйте DsIconButton с доступным названием.
- `loading` показывает спиннер по центру, сохраняет ширину, цвет и доступное имя кнопки. Кнопка остаётся в последовательности Tab, объявляет `aria-busy` и `aria-disabled`, блокирует повторное действие и отправку формы. Родитель управляет загрузкой, сообщает результат через `role="status"` и обрабатывает ошибку. Не меняйте подпись во время загрузки, если важно сохранить исходную ширину.
- Не отключайте отправку формы только из-за незаполненных полей: оставляйте кнопку доступной, после отправки показывайте ошибки у полей и переводите фокус к первому ошибочному полю.
- `disabled` используйте для действительно недоступного действия; он исключает кнопку из последовательности Tab. Причину и следующий шаг объясняйте видимым текстом рядом. Подсказка на недоступной кнопке не заменяет объяснение.
- Кнопка активируется клавишами Enter и Space, фокус виден при навигации с клавиатуры. В форме задайте `type="submit"`; по умолчанию используется `button`. Для переходов между страницами используйте ссылку.

## Пример кода

```jsx
import { useState } from 'react';
import { DsButton } from '@primasoftllc/design-system';

export function SaveChanges({ onSave }) {
  const [loading, setLoading] = useState(false);
  const [message, setMessage] = useState('');

  async function save() {
    setLoading(true);
    setMessage('Сохраняем изменения…');
    try {
      await onSave();
      setMessage('Изменения сохранены.');
    } catch {
      setMessage('Не удалось сохранить изменения. Попробуйте ещё раз.');
    } finally {
      setLoading(false);
    }
  }

  return (
    <div>
      <DsButton icon="save" loading={loading} onClick={save}>
        Сохранить изменения
      </DsButton>
      <p role="status">{message}</p>
    </div>
  );
}
```
