## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-brand`, `ds-on-brand` | Заливка и содержимое primary |
| `ds-accent`, `ds-accent-on` | Заливка и содержимое accent |
| `ds-danger-solid`, `ds-on-solid` | Заливка и содержимое danger |
| `ds-brand-subtle`, `ds-brand-text` | Заливка и содержимое subtle |
| `ds-surface`, `ds-fg`, `ds-border-field` | Заливка, содержимое и граница secondary |
| `ds-fg-muted` | Содержимое ghost |
| `ds-surface-hover`, `ds-surface-active` | Фон secondary и ghost при наведении и нажатии |
| `ds-overlay-hover`, `ds-overlay-press` | Оверлей цвета содержимого при наведении и нажатии заливных тонов |
| `ds-surface-disabled`, `ds-fg-disabled` | Заливка недоступных заливных тонов и содержимое всех недоступных кнопок; загрузка сохраняет цвета своего тона |
| `ds-border` | Граница недоступных secondary и ghost; их фон прозрачен |
| `ds-control-h-sm`, `ds-control-h`, `ds-control-h-lg` | Высота размеров sm, md и lg с учётом плотности |
| `ds-control-pad-x` | Горизонтальные отступы md и lg; у sm — 10 px |
| `ds-gap-sm` | Интервал между текстом и иконкой |
| `ds-radius-control` | Скругление кнопки |
| `ds-type-ui`, `ds-type-body-strong` | Текст sm и md; усиленный текст lg |
| `ds-icon-sm`, `ds-icon` | Единый размер левой и правой иконок и спиннера: sm использует ds-icon-sm, md/lg — ds-icon |
| `ds-focus-width`, `ds-focus-color`, `ds-focus-offset` | Общее кольцо клавиатурного фокуса |
| `ds-transition-control` | Плавность изменения оформления |
