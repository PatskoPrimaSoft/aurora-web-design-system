## Правила применения

- Используйте меню для компактного списка действий или выбора варианта. Важное основное действие оставляйте видимой кнопкой.
- Передавайте в `trigger` кнопку `DsButton` или `DsIconButton`. У кнопки с иконкой обязателен понятный `label`; меню само добавляет атрибуты раскрытия.
- Обрабатывайте выбор через общий `onSelect` или `onClick` пункта. Если заданы оба, сначала вызывается `onSelect`, затем `onClick`.
- `type="action"` — обычное действие, `type="radio"` — одиночный выбор, `type="checkbox"` — множественный. Для вариантов выбора задавайте `checked`; выбранное значение хранит потребитель. В одном меню используйте одну логическую группу radio.
- Действие и radio закрывают меню и возвращают фокус на кнопку. Checkbox оставляет меню открытым; `closeOnSelect` пункта переопределяет это поведение. Старый `checked` без `type` сохраняет только визуальную галочку.
- Разделяйте связанные действия через `{divider: true}`. `tone="danger"` используйте для действий с существенными последствиями; у недоступного действия объясняйте причину рядом с меню.
- `align` задаёт край привязки к кнопке, `width` — ширину в px или `auto` по содержимому. Панель ограничивается экраном и высотой 320 px, при нехватке места снизу раскрывается вверх. Длинный список прокручивается; длинные подписи переносятся и остаются видимыми целиком без наведения.
- В браузерах с Popover API панель выводится в верхнем слое и не обрезается контейнером. В остальных используется фиксированное размещение; избегайте обрезающих контейнеров с transform. В каталоге границей экрана меню служит его iframe.
- Панель получает доступное имя от кнопки. Для отдельного названия задайте `menuLabel`.
- `header` и `footer` подходят для короткого контекста. Не размещайте в них поля формы и дополнительные кнопки: клавиатурная навигация рассчитана на пункты меню.
- Для управляемого раскрытия передавайте `open` вместе с `onOpenChange`.
- Enter, Space и ↓ открывают меню с фокусом на первом доступном пункте, ↑ — на последнем. В меню ↑/↓ перемещают фокус, Home/End переходят к краям, Enter/Space выбирают пункт. Escape закрывает меню и возвращает фокус на кнопку; Tab закрывает и продолжает обход страницы. Клик снаружи также закрывает меню.
- `shortcut` — только видимая подсказка. Само сочетание клавиш должно быть реализовано приложением.
- Ввод первых букв переводит фокус на совпадающую подпись; повтор одной буквы перебирает совпадения. Недоступные пункты пропускаются. Фокус подсвечивает пункт и сохраняет системное кольцо.

## Пример кода

```jsx
import { useState } from 'react';
import { DsButton, DsMenu } from '@primasoftllc/design-system';

export function PeriodMenu() {
  const [period, setPeriod] = useState('day');
  const options = [
    { id: 'day', label: 'Сегодня' },
    { id: 'week', label: 'За неделю' },
    { id: 'month', label: 'За месяц' },
  ];

  return (
    <div>
      <DsMenu
        trigger={<DsButton tone="secondary">Период</DsButton>}
        items={options.map(item => ({ ...item, type: 'radio', checked: item.id === period }))}
        onSelect={item => setPeriod(item.id)}
      />
      <p role="status">
        Период: {options.find(item => item.id === period).label}
      </p>
    </div>
  );
}
```
