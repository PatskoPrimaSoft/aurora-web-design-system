## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-surface-raised` | Фон раскрытой панели |
| `ds-border` | Граница панели |
| `ds-shadow-md` | Тень панели над содержимым |
| `ds-radius-md` | Скругление панели |
| `ds-radius-sm` | Скругление пункта |
| `ds-gap-xs` | Внутренний отступ панели и интервалы вокруг разделителей |
| `ds-gap-sm` | Расстояние между иконкой, подписью и подсказкой пункта |
| `ds-pad-tight`, `ds-pad-sm` | Отступы заголовка и подвала; `ds-pad-sm` также задаёт горизонтальные отступы пункта |
| `ds-control-h` | Минимальная высота пункта с учётом плотности |
| `ds-type-ui` | Текст пункта |
| `ds-fg` | Цвет обычного пункта |
| `ds-fg-muted` | Цвет иконки обычного пункта |
| `ds-fg-subtle` | Цвет подсказки сочетания клавиш |
| `ds-fg-disabled` | Цвет текста и основной иконки недоступного пункта |
| `ds-surface-hover` | Фон обычного пункта при наведении |
| `ds-danger-fg`, `ds-danger-bg` | Текст и иконка опасного действия, его фон при наведении |
| `ds-brand` | Галочка выбранного пункта |
| `ds-icon`, `ds-icon-sm` | Размер основной иконки и галочки |
| `ds-type-caption`, `ds-font-mono` | Размер и моноширинное начертание подсказки сочетания клавиш |
| `ds-divider` | Разделители и границы заголовка и подвала |
| `ds-focus-width`, `ds-focus-color`, `ds-focus-offset` | Кольцо клавиатурного фокуса |
