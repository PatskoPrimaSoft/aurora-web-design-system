## Пример кода

Переход в собственной разметке. Готовые компоненты уже подключают нужные стили.

```css
.custom-control { transition: var(--ds-transition-control); }
@media (prefers-reduced-motion: reduce) {
  .custom-control { transition: none; }
}
```
