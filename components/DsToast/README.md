## Правила применения

- Показывайте тост как краткую обратную связь после действия. Сообщение, которое должно оставаться доступным на странице, оформляйте через DsBanner.
- Используйте одно короткое действие, обычно «Отменить». Не размещайте в тосте форму или несколько равнозначных действий.
- Размещайте уведомления в DsToastStack на уровне страницы. Новые сообщения добавляйте в конец списка; позиция стека задаётся через position.
- Родитель управляет появлением, закрытием и временем показа: встроенного таймера нет. onClose только сообщает о нажатии — тост нужно убрать из состояния.
- Тост не переносит фокус на себя. Действие и закрытие доступны клавишей Tab и активируются Enter или Space.
- danger объявляется через alert, остальные тона — через status. Не дублируйте сообщение во второй live-области.
- Инверсная поверхность и статусные цвета иконок назначаются компонентом; не подставляйте обычные статусные цвета для светлого фона.

## Пример кода

```jsx
import { useState } from 'react';
import { DsButton, DsToast, DsToastStack } from '@primasoftllc/design-system';
import '@primasoftllc/design-system/styles.css';

export function SaveSettings() {
  const [saved, setSaved] = useState(false);
  return <>
    <DsButton onClick={() => setSaved(true)}>Сохранить настройки</DsButton>
    <DsToastStack>
      {saved && <DsToast tone="success" onClose={() => setSaved(false)}>
        Настройки сохранены.
      </DsToast>}
    </DsToastStack>
  </>;
}
```
