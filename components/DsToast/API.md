## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-surface-inverse` | Инверсная поверхность тоста |
| `ds-fg-on-inverse` | Текст, кнопка закрытия и нейтральная иконка |
| `ds-info-fg-on-inverse`, `ds-success-fg-on-inverse`, `ds-warning-fg-on-inverse`, `ds-danger-fg-on-inverse` | Статусная иконка на инверсной поверхности |
| `ds-fg-action-on-inverse` | Цвет действия |
| `ds-control-h-lg` | Минимальная высота тоста |
| `ds-pad-tight`, `ds-pad-sm`, `ds-pad-md` | Внутренние отступы |
| `ds-gap-sm-plus` | Интервалы между иконкой, текстом и кнопками |
| `ds-gap-sm` | Интервал между тостами в стеке |
| `ds-radius-md`, `ds-shadow-lg` | Скругление и тень тоста |
| `ds-radius-xs` | Скругление кнопки закрытия |
| `ds-icon`, `ds-icon-sm` | Размеры статусной иконки и иконки закрытия |
| `ds-type-body`, `ds-type-ui` | Типографика сообщения и действия |
