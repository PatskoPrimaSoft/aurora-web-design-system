## Правила применения

- Полосы по умолчанию — эко-вождение: Плохо / Норма / Хорошо / ЛУЧШИЙ. Свои полосы перечисляйте по возрастанию.
- Без значения шкала показывает прочерк и без маркера.
- `showScale` — числовые границы под шкалой, для экрана настроек, не для строки.
- Это замена радиальным шкалам: круговых диаграмм в системе нет.

## Пример кода

```jsx
import { DsScoreBar } from '@primasoftllc/design-system';

export function DrivingScore() {
  return <DsScoreBar value={78} label="Эко-вождение" unit="баллов" />;
}
```
