## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-field-h` | Высота поля с учётом плотности |
| `ds-surface`, `ds-fg` | Поверхность и значение |
| `ds-bg` | Поверхность поля только для чтения |
| `ds-surface-disabled`, `ds-fg-disabled` | Недоступное поле |
| `ds-border-field`, `ds-border-field-hover`, `ds-border-width`, `ds-radius-md` | Граница и скругление общей оболочки DsField |
| `ds-brand`, `ds-focus-color`, `ds-focus-width`, `ds-focus-offset` | Фокус |
| `ds-danger-solid`, `ds-danger-fg` | Ошибка и обязательность |
| `ds-type-body`, `ds-type-caption`, `ds-weight-medium` | Значение, подпись и пояснение |
| `ds-fg-muted`, `ds-fg-subtle` | Подпись и подсказка |

Встроенный календарь и меню времени рисует браузер; токены Aurora задают оболочку поля.
