Квадратная кнопка только с иконкой; `label` обязателен — он становится `aria-label` и `title`.

**Потребитель задаёт** `icon`, `label`, при необходимости `tone`, `size`, `active`, `dot`, `rotate`, `loading`, `disabled`, `onClick`.

- `tone="onHeader"` — для хрома шапки: чернила `--ds-header-icon-fg`, ховер `--ds-header-hover`.
- `active` — включённое состояние: брендовый тинт и брендовые чернила; например, применённый фильтр.
- `dot` — акцентная точка «здесь что-то применено». Количество показывайте отдельным числовым счётчиком.
- `rotate` несёт смысл (курс, линейка), никогда не украшение.

**Не делайте:** иконку-кнопку без `label`; двенадцать семантических пресетов старой библиотеки — передайте `icon`.
