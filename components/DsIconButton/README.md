## Правила применения

- Используйте кнопку с иконкой для узнаваемого действия в ограниченном пространстве. Для неоднозначного или важного действия предпочтительнее `DsButton` с видимым текстом.
- `label` обязателен: он выводится как визуально скрытый текст внутри кнопки, задаёт доступное имя и системную подсказку по наведению и фокусу. Текст остаётся доступным скринридерам и сервисам перевода, в том числе при загрузке. Escape закрывает видимую подсказку, сохраняя внешний диалог открытым. Называйте действие, например «Обновить данные», а не изображение «Стрелка».
- `onHeader` предназначен для поверхности шапки и использует её цвета.
- Передавайте `active` только переключателю: `true` и `false` отражаются в `aria-pressed`. У обычного действия этот параметр опускайте. Состоянием управляет родитель.
- `dot` отмечает наличие применённой настройки, но не заменяет доступное описание или числовой счётчик. Связывайте кнопку с пояснением через `aria-describedby`. Открывающая настройки кнопка с индикатором остаётся обычным действием; `active` нужен переключателю. `rotate` передаёт смысл, например направление курса.
- Группу действий связывайте с объектом и давайте ей доступное название. Дополнительные действия открывайте через `DsMenu`, который управляет клавиатурой и возвращает фокус на кнопку. После сохранения или отмены формы возвращайте фокус на действие редактирования.
- При `loading` кнопка показывает спиннер, сохраняет размеры, тон и клавиатурный фокус. `aria-busy` и `aria-disabled` объявляют загрузку, повторное действие и отправка формы блокируются. Родитель завершает загрузку и сообщает результат или ошибку рядом с действием; название действия сохраняйте стабильным.
- Стандартные атрибуты HTML-кнопки и обработчики передаются элементу. Тип по умолчанию — `button`; для отправки формы задайте `type="submit"`.
- Для `disabled` объясняйте причину видимым текстом; при необходимости связывайте его с кнопкой через `aria-describedby`.
- Enter и Space выполняют действие; Tab перемещает фокус между доступными кнопками. Размеры следуют токенам контролов и меняются с плотностью интерфейса.

## Пример кода

```jsx
import { useState } from 'react';
import { DsIconButton } from '@primasoftllc/design-system';

export function ActiveObjectsFilter() {
  const [active, setActive] = useState(false);

  return (
    <DsIconButton
      icon="filter_alt"
      label="Только активные объекты"
      active={active}
      onClick={() => setActive(value => !value)}
    />
  );
}
```
