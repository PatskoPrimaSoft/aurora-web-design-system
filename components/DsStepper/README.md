## Правила применения

- Используйте для последовательной задачи: импорта, экспорта или создания объекта. Для независимых разделов подходят вкладки.
- `active` — индекс текущего шага с нуля. Содержимое этапа, проверку данных и переход вперёд реализует приложение.
- По умолчанию завершёнными считаются шаги перед `active`. При возврате это состояние пересчитывается. Чтобы сохранить завершённые этапы независимо от текущего, передавайте их индексы в `completed`.
- С `onSelect` доступны текущий и завершённые шаги. Остальные недоступны. Без `onSelect` компонент только показывает прогресс.
- Tab переводит фокус между доступными шагами; Enter или Space вызывает `onSelect`. Текущий шаг отмечен `aria-current="step"`.
- Выбирайте короткие подписи; `hint` подходит для краткого пояснения. На узком экране длинная цепочка прокручивается горизонтально.
- Для длинной задачи используйте отдельный экран; в диалоге ограничивайтесь двумя–тремя шагами.

## Пример кода

```jsx
import { useState } from 'react';
import { DsButton, DsStepper } from '@primasoftllc/design-system';

const steps = [
  { id: 'file', label: 'Файл' },
  { id: 'fields', label: 'Поля', hint: 'Сопоставление' },
  { id: 'check', label: 'Проверка' },
];
const content = ['Выберите файл.', 'Сопоставьте поля.', 'Проверьте данные.'];

export function ImportSteps() {
  const [active, setActive] = useState(0);

  return (
    <div>
      <DsStepper steps={steps} active={active} onSelect={setActive} />
      <p role="status">{content[active]}</p>
      <DsButton disabled={active === steps.length - 1} onClick={() => setActive(active + 1)}>
        Далее
      </DsButton>
    </div>
  );
}
```
