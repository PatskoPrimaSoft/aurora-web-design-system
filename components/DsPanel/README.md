## Правила применения

- Используйте панель для связанного содержимого внутри страницы. Внешние отступы и ширину задаёт родитель.
- `title` задаёт заголовок; уровень по умолчанию h2, измените его через `headingLevel` согласно структуре страницы. Для обычного текста используйте `none`. `eyebrow` — короткая категория над ним; действия шапки размещайте в `actions`, итоговые действия — в `footer`.
- Заголовок задаёт доступное имя панели. Без него передайте `aria-label` или `aria-labelledby`; внешний `aria-labelledby` имеет приоритет.
- Шапка переносит длинный заголовок и действия при нехватке ширины. В подвале действия выравниваются справа и переносятся; размещайте вторичное действие перед основным. Для собственного расположения оберните содержимое подвала в контейнер.
- `padding={false}` подходит для таблицы или карты, которая должна доходить до краёв тела. Отступы шапки и подвала сохраняются.
- `flush` убирает внешнюю рамку и скругление для панели внутри региона каркаса. Разделители шапки и подвала сохраняются.
- По умолчанию панель растёт с содержимым. Для прокрутки только тела включите `scroll` и ограничьте высоту через `height` или родительскую раскладку. Шапка и подвал остаются на месте. Тело доступно через Tab; стрелки и Page Up / Page Down прокручивают его.
- Тело — flex-колонка: дочерний элемент с `flex: 1` заполняет доступную высоту. Для обычного потока документа задайте `bodyStyle={{ display: 'block' }}`.
- `actions` и `footer` можно передать через параметры или дочерние элементы с `slot`. Явно заданный параметр имеет приоритет; `null` скрывает соответствующую область.
- Загрузку и результат показывает содержимое: используйте `DsSpinner`, `DsEmptyState` и обычное объявление результата через `role="status"`. При обновлении сохраняйте действия на месте и блокируйте повторный запуск через `loading` кнопки.
- Панель сама не управляет фокусом и не является диалогом. Клавиатурное поведение задают вложенные элементы.

## Пример кода

```jsx
import { useState } from 'react';
import { DsPanel, DsField, DsButton } from '@primasoftllc/design-system';

function VehiclePanel() {
  const [plate, setPlate] = useState('AB 3390-6');
  const [savedPlate, setSavedPlate] = useState(plate);

  return (
    <DsPanel
      eyebrow="Транспорт"
      title="Scania R450"
      footer={<DsButton onClick={() => setSavedPlate(plate)}>Сохранить</DsButton>}
    >
      <DsField label="Госномер" value={plate} onChange={event => setPlate(event.target.value)} />
      <p role="status">Сохранено: {savedPlate}</p>
    </DsPanel>
  );
}
```
