## Токены

| Токен | За что отвечает |
| --- | --- |
| `ds-surface` | Основная поверхность панели |
| `ds-border` | Внешняя граница и разделители шапки и подвала |
| `ds-radius-panel` | Скругление панели, если не задан flush |
| `ds-toolbar-h` | Минимальная высота шапки |
| `ds-pad-md` | Отступы тела и горизонтальные отступы шапки и подвала |
| `ds-pad-sm` | Вертикальные отступы подвала |
| `ds-gap-sm` | Интервалы между содержимым шапки и её действиями, элементами подвала |
| `ds-bg` | Поверхность подвала |
| `ds-type-section`, `ds-fg-strong`, `ds-tracking-tight` | Типографика и цвет заголовка |
| `ds-type-eyebrow`, `ds-fg-subtle`, `ds-tracking-eyebrow` | Типографика и цвет категории над заголовком |

Вложенные кнопки и поля используют собственные токены.
