Тема задаётся контейнеру и действует на всё его содержимое

data-ds-appearance="dark" или "light" задаёт тему для всего элемента и его вложенных компонентов. Все компоненты внутри автоматически получают соответствующие значения цветовых переменных.

Если внутри нужно использовать другую тему, её можно явно переопределить на вложенном контейнере.

<body data-ds-appearance="dark"> <aside>тёмная тема</aside> <main data-ds-appearance="light"> светлая тема </main> </body>

Компоненты не знают, какая тема включена

Компонент всегда использует одни и те же переменные:

background: var(--ds-surface); color: var(--ds-fg); border: 1px solid var(--ds-border);

Он не содержит отдельных стилей для light и dark. Тема меняет только значения переменных --ds-*, а сам код компонента остаётся одинаковым.

То есть логика такая: тема → подставляет значения переменных → компонент использует переменные.
