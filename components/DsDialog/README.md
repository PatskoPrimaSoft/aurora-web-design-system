## Правила применения

Используйте диалог для подтверждения действия, создания или изменения одного объекта и короткой задачи. Для сложного процесса выбирайте отдельную страницу. Не открывайте несколько диалогов друг над другом.

Задавайте `open` и меняйте его в `onClose` и обработчиках действий. Диалогу нужен видимый `title`; без заголовка обязательно задайте `aria-label`. `description` кратко объясняет последствия, `children` содержит основную часть.

Фокус переходит на первый доступный контрол, Tab и Shift+Tab удерживают его внутри окна. После закрытия фокус возвращается к элементу, который был активен перед открытием. Escape закрывает верхний слой; клик по затемнению и крестик вызывают `onClose`. При `dismissable={false}` Escape и затемнение не закрывают окно, но крестик остаётся. Без `onClose` эти способы закрытия недоступны; предусмотрите завершение задачи через действия.

Выбирайте размер по содержимому: `sm` — подтверждение, `md` — короткая форма, `lg` — две колонки, `xl` — таблица или карта. На узком экране ширина ограничена доступным местом. Высота зависит от содержимого; при `scroll` длинное тело прокручивается отдельно от заголовка и действий.

В `actions` передавайте кнопки в порядке: отмена, затем одно главное действие. Название главной кнопки повторяет действие из заголовка. Для удаления или архивирования используйте `tone="danger"` и опасную кнопку. Объясняйте последствия конкретно; избегайте «Вы уверены?», «ОК» и «Да».

## Пример кода

```jsx
import { useState } from 'react';
import { DsButton, DsDialog } from '@primasoftllc/design-system';

export function Example() {
  const [open, setOpen] = useState(false);
  const [archived, setArchived] = useState(false);
  const close = () => setOpen(false);

  return (
    <>
      <DsButton tone="danger" onClick={() => setOpen(true)}>
        Переместить в архив…
      </DsButton>
      <p role="status">{archived ? 'Объект перемещён в архив.' : ''}</p>
      <DsDialog
        open={open}
        size="sm"
        tone="danger"
        title="Переместить объект «Volvo FH16» в архив?"
        description="Объект пропадёт с карты. Его история останется доступна в отчётах."
        onClose={close}
        actions={[
          <DsButton key="cancel" tone="secondary" onClick={close}>Отмена</DsButton>,
          <DsButton key="archive" tone="danger" onClick={() => {
            setArchived(true);
            close();
          }}>Переместить в архив</DsButton>,
        ]}
      />
    </>
  );
}
```
