## Токены

| Токен | За что отвечает |
| --- | --- |
| ds-n-a60 | Затемнение за диалогом |
| ds-surface | Поверхность окна |
| ds-bg | Фон области действий |
| ds-border | Граница окна и разделители заголовка и действий |
| ds-radius-xl | Скругление окна |
| ds-shadow-lg | Тень над затемнением |
| ds-fg-strong, ds-type-title, ds-tracking-tight | Цвет, шрифт и межбуквенный интервал заголовка |
| ds-fg-muted, ds-type-body | Описание и цвет кнопки закрытия |
| ds-{tone}-bg, ds-{tone}-solid | Подложка и символ статуса в заголовке |
| ds-icon | Размер символов статуса и закрытия |
| ds-radius-md, ds-radius-xs | Скругление подложки статуса и кнопки закрытия |
| ds-pad-xl | Отступ окна от краёв демонстрационной области или экрана |
| ds-pad-md, ds-pad-lg, ds-pad-sm | Внутренние отступы заголовка, тела и действий |
| ds-gap-sm-plus, ds-gap-sm | Интервалы в заголовке и между кнопками действий |
