Это API ViewBreakpointService из приложения. more('m') означает «L и шире». В документации указывайте результирующий диапазон.

Правила

Четыре диапазона, три порога перехода: 720, 960 и 1140px. Локальная адаптация — через container queries.
Диапазоны не пересекаются: S — ширина меньше 720px, M начинается с 720px. Целочисленные верхние границы — 719, 959 и 1139px.
Для поведения «начиная с размера» используйте more() / less(). equal() подходит для одного конкретного диапазона.

Ширина контента

Формы и текстовые страницы ограничивайте токеном --ds-content-max (1440px), длинный текст — --ds-content-max-prose (72ch). Карта и таблицы используют доступную ширину. Ограничение не требует отдельного переключения на XL.
