## Токены

| Токен | За что отвечает |
| --- | --- |
| ds-bg | Фон каркаса и пространства между регионами |
| ds-fg | Основной цвет текста, наследуемый содержимым |
| ds-panel-w | Ширина левого региона, если не задан leftWidth; зависит от плотности интерфейса |
| ds-gap-sm-plus | Внутренние отступы каркаса и интервалы между регионами при gap=true |
