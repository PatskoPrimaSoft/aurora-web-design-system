## Правила применения

- Используйте для каркаса страницы: `header` и `pageHeader` находятся над содержимым, `footer` — под ним; `left` и `right` располагаются по сторонам основного региона. Отсутствующий регион не занимает места.
- Основное содержимое передавайте в `children`. Компонент создаёт `main` и боковые `aside`: не вкладывайте в него второй `main`, а нескольким боковым областям задавайте понятные заголовки.
- Высоту каркаса задаёт родитель. Для экрана с ограниченной высотой родитель должен иметь определённую высоту; прокрутку содержимого организует приложение. DsPageLayout сам не включает прокрутку регионов.
- Боковые регионы имеют заданную ширину и автоматически не скрываются и не переходят под основное содержимое. На узком экране приложение уменьшает их ширину, скрывает или открывает отдельно.
- `gap={false}` убирает внутренние отступы каркаса и интервалы между регионами, например для карты. Отступы самого содержимого определяют вложенные компоненты.
- Вместо props можно передать детей с `slot="header"`, `slot="pageHeader"`, `slot="left"`, `slot="right"` или `slot="footer"`; поддерживается и `data-slot`. Используйте один способ назначения каждого региона.

## Пример кода

```jsx
import { DsAppHeader, DsPageLayout } from '@primasoftllc/design-system';

export function ObjectsPage() {
  return (
    <div style={{ height: 600 }}>
      <DsPageLayout
        header={<DsAppHeader product="Aurora" section="Мониторинг" user="a.ivanov" />}
        pageHeader={<header><h1>Объекты</h1></header>}
      >
        <p>Содержимое страницы</p>
      </DsPageLayout>
    </div>
  );
}
```
